# 抗跌观察池

大盘（创业板指）**当日跌幅 ≤ -1.5%**（可用 `--drop` 调）时，全市场扫描抗跌个股。筛选条件：近 20 日未破前低 + 20 日跑赢大盘 5% + 近 5 日缩量 + 流通市值 50-500 亿 + Q2 业绩展望偏正。结果仅作观察种子，**不构成买卖建议**。

## 设计理念

弱势行情中，能逆势抗跌（不破前低、相对强势、缩量惜售）的个股，往往是下一轮企稳反弹的领涨候选。本 skill 在大盘大跌时自动扫描这类股票，**只看不动**。

## 使用方式

输入 `/kangdie` 触发执行。

## 执行步骤

1. **运行前先检查当天数据是否已存在**：
   ```bash
   ls .claude/skills/kangdie/data/kd_$(date +%Y-%m-%d).json 2>/dev/null
   ```
   - 若文件**已存在**：提示用户"今日数据已存在"（可用 Read 查看其 `count` 和 `trigger`），重新运行会覆盖。询问是否重跑。
   - 若**不存在**：继续步骤 2。

2. 确认依赖已安装：
   ```bash
   cd .claude/skills/kangdie && pip install -r requirements.txt
   ```

3. 运行选股脚本：
   ```bash
   cd .claude/skills/kangdie && python main.py
   ```
   > 全程约 10-20 分钟（扫全 A ~5300 只，20 线程并发拉 OHLCV）。
   > `--no-q2` 跳过 Q2 过滤；`--drop -2` 调大跌阈值（默认 -1.5%）。

4. 脚本会：
   - 拉取创业板指 150 日 K 线，判断**今日是否大跌**（当日跌幅 ≤ 阈值，默认 -1.5%）
   - 若**未大跌**：打印提示并写空结果（`count=0`、`trigger.big_drop=false`），退出
   - 若**大跌**：拉全 A 行情 + 市值 → 先按市值 50-500 亿过滤 → 并发拉个股 70 日 OHLCV → 判定 4 条抗跌条件 → Q2 过滤
   - 结果保存到 `data/kd_YYYY-MM-DD.json`

5. 读取输出文件，向用户展示：
   - 大盘触发情况（创业板当日跌幅 vs 阈值）
   - 抗跌候选总数
   - 输出文件路径
   - 列出候选股（代码、名称、收盘价、20日涨幅、相对大盘超额、缩量比、市值、Q2）

## 筛选条件（4 条全满足）

| 条件 | 判定 | 含义 |
|------|------|------|
| 不破前低 | `min(low[-20:]) ≥ min(low[-60:-20])` | 近 20 日最低点没有跌破前 40 日最低 |
| 相对强势 | `ret20 − index_ret20 ≥ 5` | 20 日跑赢大盘至少 5 个百分点 |
| 缩量 | `mean(vol[-5:]) < mean(vol[-20:]) × 0.8` | 近 5 日均量不足近 20 日的 80% |
| 市值 | `50 ≤ market_cap ≤ 500` | 流通市值 50-500 亿（中盘） |

Q2 过滤（可选，默认开）：经 q2zhanwang 判定 `verdict=="偏正"` 通过；数据不足/失败兜底放行（只正向收紧，不误杀）。

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 大盘未大跌（跌幅 > 阈值） | 打印提示，写空结果（`count=0`），正常退出 |
| 非交易日 | 全 A 列表为空，提示"未获取到行情数据" |
| Q2 桥接失败 | 降级为跳过（不阻断主流程），所有候选 q2 字段标"跳过" |
| 候选为 0 | 属正常（条件较严），写入 count=0 |
| 已有当天数据 | 提示用户，询问是否覆盖 |

## 数据源

全程使用新浪财经接口（不走腾讯/东财 push2）：
- 全 A 列表 + 市值：`Market_Center.getHQNodeData`（node=hs_a 分页）
- 个股 OHLCV + 指数 K 线：`CN_MarketData.getKLineData`（scale=240 日K）
- Q2 财报：东方财富 datacenter-web（经 bridges 桥接 q2zhanwang）
