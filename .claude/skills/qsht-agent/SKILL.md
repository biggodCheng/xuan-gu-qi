# qsht-agent — 选股流水线

## 概述

一键运行完整的选股流水线，自动编排 大盘环境扫描 + 4 步筛选 + 1 步 Q2 业绩展望 + 1 步回踩策略复盘：

0. **大盘环境**（market_env）— 选股前扫描上证/沪深300/创业板的回撤/均线/量能/近期涨跌，给出环境判断（高位回调/超跌/震荡），**置于主报告开头**
1. **创新高**（chuangxingao）— 筛选当日收盘价创 100 个交易日新高的股票
2. **近期涨停**（zhangting）— 从创新高中筛选近15天有涨停的股票（主板>=9.5%, 科创板/创业板>=19.5%, 北交所>=29.5%）
3. **缩量回踩**（suolianghuicai）— 筛选涨停后缩量回踩的股票（策略1：连续缩量 + 价格回落）
4. **市值筛选**（shizhi）— 从缩量回踩股中筛出市值 < 200 亿的股票
5. **Q2业绩展望**（q2zhanwang）— 对第2步「近期涨停」的全部股票推断 Q2 业绩方向（偏正/中性/偏负），偏正/中性公司列入报告末尾
6. **回踩策略复盘**（backtest_pullback）— 每日自动累积：扫描全部历史 `slhc_*.json` 识别事件，回拉每只标的识别日后的真实日K，统计缩量回踩策略有效性（平均收益/MFE·MAE/胜率/涨停次日表现），用于验证"回踩涨停=兑现窗口"等假设

前 4 步筛选出的股票逐步输出到 markdown 报告；第 5 步对所有近期涨停股做 Q2 展望；第 6 步把复盘摘要（含样本量与核心统计）置于报告文档最末，完整复盘另存独立文件。

## 运行方式

```bash
python .claude/skills/qsht-agent/main.py
```

无需参数，所有参数使用默认值：
- 缩量回踩策略：策略 1（连续缩量 + 价格回落）
- shrink_ratio：0.8
- min_days：2
- 市值阈值：200 亿

## 输出

报告保存在 `.claude/skills/qsht-agent/output/{日期}.md`，包含：
- 大盘环境（上证/沪深300/创业板：回撤/均线/量能/近期涨跌 + 环境判断，**位于报告开头**）
- 筛选流水线统计（每步筛选数量）
- 第1步：创新高股票列表
- 第2步：近期涨停股票列表
- 第3步：缩量回踩股票列表
- 第4步：市值<200亿股票列表
- 最终结果汇总
- 第5步：Q2业绩展望·近期涨停（表格：展望/置信度/净利同比/营收同比等）
- 偏正/中性公司列表（中文逗号分隔，便于一眼看出前景偏正面的涨停股）
- 第6步：回踩策略复盘摘要（截至日期·样本跨度·事件/股票数·平均末值收益·MFE/MAE·胜率·涨停次日下跌占比，**位于文档最末**）

完整复盘报告另存 `.claude/skills/qsht-agent/output/pullback_review_{日期}.md`（逐事件走势明细 + 涨停兑现表 + 统计汇总）；统计快照存 `output/pullback_stats.json`。

运行完成后，使用 Read 工具读取报告文件并向用户展示完整内容。

## ⚠️ 注意事项与反例

### 本 skill 是编排器，不是新逻辑
本 skill **不实现任何筛选/分析逻辑**，仅通过 subprocess 串联调用子 skill：chuangxingao → zhangting → suolianghuicai → shizhi（4 步筛选）+ q2zhanwang（Q2 展望）。所有能力来自子 skill，参数也由子 skill 的默认值承载，本 skill 不覆盖。

### ❌ 不要做（反例黑名单）

| 不要 | 原因 | 正确做法 |
|---|---|---|
| 期望本 skill 实现新的筛选条件 | 它只编排，无独立筛选逻辑 | 改对应的子 skill |
| 在非交易日运行 | 创新高步骤取不到行情，管道终止 | 工作日收盘后再跑 |
| 中途中断执行 | 4 步筛选 + Q2 展望串行，打断会导致报告不完整 | 耐心等全部完成 |
| 自行修改子 skill 默认参数 | 默认值（策略1/0.8/2天/200亿）已调优 | 如需改，先理解对下游的影响 |

### 已知行为

- 第0步大盘环境在选股前先跑（拉指数 K 线约 2–3 秒）；独立于主漏斗，接口异常时跳过该 section，不阻断
- 任一步骤结果为 **0 只**时，管道**自动终止**并输出部分报告（该步及后续列表省略）
- 若当天提前终止，报告只含「筛选流水线统计」+「最终汇总」两段、无中间股票列表——属正常，**非格式错误**
- 每步运行数分钟（并发获取全市场数据），第5步 Q2 展望对近百只涨停股逐一拉财报再增 1–3 分钟，第6步回踩复盘拉历史标的日K约增 0.5–1 分钟，全程约 10–25 分钟
- 第5步 Q2 展望独立于下游漏斗：只要近期涨停非空就分析（即使缩量回踩/市值为 0 提前终止也会跑）
- 第5步失败不阻断主报告：财报接口异常或全部数据不足时，报告末尾显示提示行而非崩溃
- 第6步回踩复盘独立于主漏斗、且**每日自动累积样本**：只要历史存在 `slhc_*.json` 就会重算（即使当日缩量回踩为 0 提前终止也会跑）；复盘失败/无历史样本时跳过该 section，不崩溃
- 第6步为**小样本探索性分析**（样本量见报告），结论非统计显著，不作为策略定型依据
- 中间结果保存在各 skill 的 `data/` 目录（Q2 展望见 `q2zhanwang/data/batch_{日期}.json`，回踩复盘见 `qsht-agent/output/pullback_*`），可单独查看
