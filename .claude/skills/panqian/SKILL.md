# panqian — 盘前外部温度计

## 用途

A股盘前(建议 7:30–9:00)跑一次,采集隔夜外盘 + 国际事件,产出**「盘前外部温度计.md」**——四维信号(美股/A50+中概/汇率+大宗/国际事件)+ 隔夜定调 + 历史经验映射 + 你的盘前研判 checkpoint。

**核心理念**(对齐 fupan + 用户"少交易+严纪律"):**不预测涨跌**,只陈列客观事实。隔夜信号是"外部环境",开盘方向由盘口决定。一个告诉你"今天会涨"的工具会喂给过度交易本能——这个 skill 故意不给结论。

## 与现有工具的边界

| 工具 | 职责 | 时间 | 数据方向 | 关系 |
|------|------|------|---------|------|
| **panqian(本 skill)** | 隔夜外部信号 → 盘前温度计 | **盘前** | **向外·全球** | fupan 对照引用 |
| fupan | A股内部结构 → 次日剧本 | 盘后 | 向外·境内 | 读 panqian 做对照 |
| market_regime | A股市况总开关 🔴🟡🟢 | 盘中/盘后 | 向内 | fupan 复用 |
| trade_review.py | 周复盘,盯账户纪律 | 周末 | 向内·账户 | 互补 |

## 运行方式

```bash
python .claude/skills/panqian/main.py              # 默认盘前跑(建议 7:30–9:00)
python .claude/skills/panqian/main.py --note "..." # 加备注
```

- **手动跑,不挂 cron**(用户偏好手动触发,不喜定时打扰)。
- **自包含**:`main.py` 自己拉 4 维数据,各维失败不阻断,关键维缺失报告顶部明示。
- 全程约 5–15 秒(新浪行情秒级 + 东财新闻翻页 3–12 页)。

## 输出

`.claude/skills/panqian/output/{日期}.md`:第0步隔夜定调(非涨跌预测)/ 第1-4步四维数据 / 第5步历史经验映射(非预测)/ 第6步人工研判 checkpoint / 取数质量。

## 边界条件

| 场景 | 处理 |
|------|------|
| 关键维(A50/美股)全失败 | 报告顶部明示"⚠️ 外部信号缺失,研判可靠性低" |
| 新闻源(东财)失败 | 第4步 ⚠️"自动抓取失败"+提示手动补充,其余维照常 |
| 美股数据 ≠ 最近美股交易日 | ⚠️"数据过期非昨夜",拒绝使用 |
| 盘中/美股未收盘时跑 | 提示"美股未收盘,建议盘前 7:30 后跑" |
| 各维独立失败 | 该维标 ⚠️,不阻断其他维 |

## ❌ 反例黑名单

| 不要 | 原因 | 正确做法 |
|---|---|---|
| 把第0步定调当涨跌预测 | 定调是"外部环境"非"今天涨跌" | 开盘方向由盘口决定,报告只陈列外部事实 |
| 据"历史经验映射"下单 | 经验是统计倾向非必然 | 映射只辅助研判,据此下单=赌大小 |
| 据报告赌开盘(高开追/低开杀) | **这是用户15月亏18.4万的核心姿势** | 等盘口实际信号,信号触发才动手 |
| 跳过第6步研判checkpoint | 报告不给结论,研判才是精华 | 填警惕信号+纪律自检 |
| 新闻自动抓没兜底就全信 | 可能漏重大事件 | 看⚠️或自知有突发时手动补充 |

## 注意

- 隔夜外盘接口(新浪行情/东财新闻)均有改版/限频风险,失败时该维标 ⚠️ 不阻断;关键维缺失明示。接入新源须保留"probe 实测→fixture 契约→parser 校准"流程(见 `probes/probe_all.py`)。
- 第6步研判本质是主观的,脚本只给客观数据 + checkpoint 占位,结论由人填——设计意图,非功能缺失。
- A50/大宗 pct 由 price+昨收自算(新浪 hf_ 无 pct 字段);汇率 pct 取 sina fx `[11]` 字段(语义有 sina 脏数据嫌疑,详见 `pk/fx_commodity.py` docstring)。
- 报告为客观陈列 + 经验映射,**不预测涨跌,不构成投资建议**;主观部分需结合自身仓位与心态研判。
