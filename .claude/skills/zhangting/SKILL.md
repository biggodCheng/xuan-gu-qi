# 涨停筛选器

从创新高股票 JSON 文件中，筛选出最近15天内有涨停的股票。涨停阈值按板块区分：主板 >= 9.5%、科创板/创业板 >= 19.5%、北交所 >= 29.5%。

## 使用方式

输入 `/zhangting <json文件路径>` 触发执行。

例如: `/zhangting .claude/skills/chuangxingao/data/2026-05-24.json`

**缺少文件路径时**，自动查找 `.claude/skills/chuangxingao/data/` 下最新的 `*.json`（非 `zt_`/`slhc_`/`sz_` 前缀）文件。若无可用文件，提示用户先运行 `/chuangxingao`。

## 执行步骤

1. 确认依赖已安装：
   ```bash
   cd .claude/skills/zhangting && pip install -r requirements.txt
   ```

2. 运行筛选脚本：
   ```bash
   cd .claude/skills/zhangting && python main.py <json文件路径>
   ```

3. 脚本会：
   - 读取指定的 JSON 文件，提取股票列表
   - 并发获取每只股票最近20个交易日的K线数据（约1-3分钟）
   - 计算每日涨幅，按板块阈值筛选涨停股（主板>=9.5%, 科创板/创业板>=19.5%, 北交所>=29.5%）
   - K线获取失败的股票会自动重试，并在结果中报告失败数量
   - 结果保存到源文件同目录下的 `zt_<date>.json`

4. 读取输出文件，向用户展示结果摘要：
   - 涨停股数量 / 总输入数量
   - 输出文件路径
   - 列出前10只股票（代码、名称、涨停日期、涨幅、收盘价）

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 文件路径不存在 | 提示"文件不存在"，建议先运行 `/chuangxingao` |
| JSON 格式错误 | 提示"文件格式异常"，展示期望格式 |
| 无涨停股命中 | 属正常情况，提示"创新高中近期无涨停股" |
| API 请求超时 | 脚本有并发重试机制；若大面积失败，提示重试 |
