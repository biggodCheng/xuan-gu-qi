# 涨停筛选器

从创新高股票 JSON 文件中，筛选出最近15天内有涨停的股票。涨停阈值按板块区分：主板 >= 9.5%、科创板/创业板 >= 19.5%、北交所 >= 29.5%。

## 使用方式

输入 `/zhangting <json文件路径>` 触发执行。

例如: `/zhangting .claude/skills/chuangxingao/data/2026-05-24.json`

**缺少文件路径时**，自动查找 `.claude/skills/chuangxingao/data/` 下最新的 `*.json`（非 `zt_`/`slhc_`/`sz_` 前缀）文件。若无可用文件，提示用户先运行 `/chuangxingao`。

## 执行步骤

1. 确认依赖已安装：
   ```bash
   cd .claude/skills/zhangting && pip install -r requirements.txt
   ```

2. 运行筛选脚本：
   ```bash
   cd .claude/skills/zhangting && python main.py <json文件路径>
   ```

3. 脚本会：
   - 读取指定的 JSON 文件，提取股票列表
   - 并发获取每只股票最近20个交易日的K线数据（约1-3分钟）
   - 计算每日涨幅，按板块阈值筛选涨停股（主板>=9.5%, 科创板/创业板>=19.5%, 北交所>=29.5%）
   - K线获取失败的股票会自动重试，并在结果中报告失败数量
   - 结果保存到源文件同目录下的 `zt_<date>.json`

4. 读取输出文件，向用户展示结果摘要：
   - 涨停股数量 / 总输入数量
   - 输出文件路径
   - 列出前10只股票（代码、名称、涨停日期、涨幅、收盘价）

## 边界条件与失败处理

| 触发条件 | 一线处理 | 仍失败兜底 |
|---|---|---|
| 文件路径不存在 | 提示"文件不存在"，建议先运行 `/chuangxingao` | 检查是否 cd 后误传项目根相对路径（见下方反例） |
| JSON 格式错误 | 提示"文件格式异常"，展示"输入格式"示例 | — |
| 无涨停股命中 | 属正常，提示"创新高中近期无涨停股" | — |
| API 请求超时 | 脚本并发重试 | 大面积失败时提示重试 |

## ❌ 反例黑名单

| 不要 | 原因 | 正确做法 |
|---|---|---|
| cd 进 zhangting 后传项目根相对路径 | 会被解析成 `zhangting/.claude/...` 报"文件不存在" | 用绝对路径，或不 cd 从仓库根运行 `python .claude/skills/zhangting/main.py <路径>` |
| 自行调整板块涨停阈值 | 主板 9.5% / 科创创业 19.5% / 北交所 29.5% 是规则不是参数 | 阈值固定，勿改 |
| 期望输出含非涨停股 | 本 skill 只保留近 15 天有涨停的 | 无涨停的创新高股会被过滤，属正常 |

## 流程链

本 skill 位于选股流程的**第二步**：
- 上游：`/chuangxingao` → 本 skill 的输入
- 下游：`/shizhi` 或 `/suolianghuicai` → 本 skill 的输出作为它们的输入

## 输入格式

接受 `chuangxingao` 技能输出的 JSON 文件：
```json

  "date": "2026-05-24",
  "stocks": [
    {"code": "600563", "name": "法拉电子", "close": 174.2, "high_100d": 162.36}
  ]
}
```
