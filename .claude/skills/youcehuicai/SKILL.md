# 右侧趋势回踩

大盘企稳（三指站稳 MA20）时，扫"上涨趋势中缩量回踩 MA10/MA20"的标的——这是回踩策略在上涨市的正确用法（区别于下跌市失效的 suolianghuicai）。结果仅作观察，**不构成买卖建议**。

## 设计理念

回踩策略在下跌市全面失效（胜率 5%），但在上涨趋势里有效。区别在于"在哪回踩"：本 skill 只在**大盘企稳 + 个股均线多头**时找回踩，回踩的是上升的均线（MA10/MA20），不是下跌中继的假回踩。

## 使用方式

输入 `/youcehuicai` 触发执行。独立运行，不吃上游输入。

```bash
cd .claude/skills/youcehuicai && python main.py
```
> 全程约 5-10 分钟（市值过滤后 ~1500 只，20 线程并发拉 OHLCV）。
> 数据层复用 kangdie（新浪全A+OHLCV+指数K线，经 bridges 桥接）。

## 执行步骤

1. 🔴 CHECKPOINT（运行前检查今日数据是否已存在）：
   ```bash
   ls .claude/skills/youcehuicai/data/yc_$(date +%Y-%m-%d).json 2>/dev/null
   ```
   - 已存在 → 🛑 STOP，提示"今日右侧回踩数据已扫描，重跑会覆盖"，询问确认。
   - 不存在 → 继续。

2. 运行选股脚本：
   ```bash
   cd .claude/skills/youcehuicai && python main.py
   ```

3. 脚本会：**先做企稳门控**（拉三指 60 日K线，判三指是否全部收盘站上 MA20）→ 通过才继续拉全A行情+市值 → 市值 100-500 亿过滤 → 并发拉个股 70 日 OHLCV → 判定 4 条筛选条件 → 保存 `data/yc_YYYY-MM-DD.json`。

4. 读取输出，向用户展示：企稳判定（above/total）、候选总数、输出文件路径、逐只（代码/名称/收盘/回踩均线/止损位/缩量比）。

## 前置门控（必须先满足）

三指（上证/沪深300/创业板）**全部 `close[-1] > MA20`**（收盘价站上 20 日均线）。任一指数跌破 MA20 或数据不足（<20 条）即判**未企稳**。
- 未企稳 → 打印"大盘未企稳（X指仍跌破MA20）" + 写空结果（`count=0`、`trigger.stabilized=false`、`above`/`total`）+ 退出。
- 企稳但无个股命中 → `count=0` 正常保存（条件未满足，**禁止放宽容差凑数**）。

## 筛选条件（4 条全满足）

| 条件 | 判定 | 含义 |
|------|------|------|
| 上涨趋势 | `close[-1] > MA20 > MA60` | 均线多头排列 |
| 回踩均线 | `abs(close-MA10)/MA10 < 2%` **或** `abs(close-MA20)/MA20 < 2%`（先判 MA10，命中即取，优先 MA10） | 回踩上升的均线 |
| 缩量 | `mean(vol[-3:]) < mean(vol[-20:-3]) × 0.8` | 近 3 日缩量（基期为前 17 日，排除近 3 日避免自污染） |
| 市值 | `100 ≤ market_cap ≤ 500` | 流通市值 100-500 亿（龙头） |

> 需 K线 ≥60 条，不足跳过。阈值常量在 `screener/analyzer.py`（PULLBACK_TOLERANCE/VOL_SHRINK_RATIO）。

## 边界条件

| 触发条件 | 一线处理 | 仍失败兜底 |
|---|---|---|
| 大盘未企稳（任一指跌破MA20/数据不足） | 写空 `trigger.stabilized=false`，提示不适用，退出 | — |
| 门控通过但无个股命中 | `count=0` 正常保存，**禁止放宽容差凑数** | — |
| 全A行情为空（非交易日） | 写空（带 stabilized trigger），提示"未获取到行情数据" | — |
| 市值 100-500 亿过滤后为空 | 写空结果 | — |
| 个股 OHLCV 失败 / K线<60条 | 静默跳过该股 | — |
| 新浪接口异常 | 重试 | 提示"数据获取失败，稍后重试" |

## 纪律

- **买点**：回踩均线缩量（`pullback_ma` 字段标 MA10/MA20）
- **止损**：破 MA20（`stop_loss` 字段，趋势破坏即认错）
- **止盈**：破 MA10 或加速后跟踪止盈

## ❌ 反例黑名单

| 不要 | 原因 | 正确做法 |
|---|---|---|
| 大盘未企稳时强行选股 | 回踩策略在下跌市胜率仅 5%，全面失效 | 等三指站稳 MA20 再用 |
| 回踩下跌中继的均线（MA20 下行） | 假回踩，趋势未确立 | 只做 close>MA20>MA60 多头排列时回踩上升均线 |
| 无命中时放宽 2% 容差凑数 | 制造假买点 | count=0 诚实退出，等真回踩 |
| 把右侧回踩当中线重仓 | 回踩是趋势中继买点，非主升浪 | 破 MA20 即认错，跟踪止盈 |
