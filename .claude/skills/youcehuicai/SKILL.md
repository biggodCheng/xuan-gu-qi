# 右侧趋势回踩

大盘企稳（三指站稳 MA20）时，扫"上涨趋势中缩量回踩 MA10/MA20"的标的——这是回踩策略在上涨市的正确用法（区别于下跌市失效的 suolianghuicai）。结果仅作观察，**不构成买卖建议**。

## 设计理念

回踩策略在下跌市全面失效（胜率 5%），但在上涨趋势里有效。区别在于"在哪回踩"：本 skill 只在**大盘企稳 + 个股均线多头**时找回踩，回踩的是上升的均线（MA10/MA20），不是下跌中继的假回踩。

## 使用方式

输入 `/youcehuicai` 触发执行。

```bash
cd .claude/skills/youcehuicai && python main.py
```
> 全程约 5-10 分钟（市值过滤后 ~1500 只，20 线程并发拉 OHLCV）。
> 数据层复用 kangdie（新浪全A+OHLCV+指数K线，经 bridges 桥接）。

## 前置门控（必须先满足）

三指（上证/沪深300/创业板）**全部 close > MA20**（站稳 MA20）。
不满足 → 打印"大盘未企稳（X指仍跌破MA20）" + 写空结果（`count=0`、`trigger.stabilized=false`）+ 退出。

## 筛选条件（4 条全满足）

| 条件 | 判定 | 含义 |
|------|------|------|
| 上涨趋势 | `close > MA20 > MA60` | 均线多头排列 |
| 回踩均线 | 收盘距 MA10 或 MA20 < 2% | 回踩上升的均线（优先 MA10） |
| 缩量 | `mean(vol[-3:]) < mean(vol[-20:-3]) × 0.8` | 近 3 日缩量 |
| 市值 | `100 ≤ market_cap ≤ 500` | 流通市值 100-500 亿（龙头） |

## 纪律

- **买点**：回踩均线缩量（`pullback_ma` 字段标 MA10/MA20）
- **止损**：破 MA20（`stop_loss` 字段，趋势破坏即认错）
- **止盈**：破 MA10 或加速后跟踪止盈

## 输出格式

```json
{
  "date": "2026-07-17",
  "trigger": {"stabilized": true, "above": 3, "total": 3},
  "count": 8,
  "stocks": [
    {"code": "...", "name": "...", "close": 15.3, "pullback_ma": "MA10",
     "pullback_price": 15.03, "vol_shrink": 0.62, "stop_loss": 15.02,
     "ma10": 15.03, "ma20": 15.02, "ma60": 12.97, "market_cap": 200.0}
  ]
}
```

## 数据源

全程新浪（复用 kangdie fetcher：全A列表 + 个股OHLCV + 指数K线 + 市值），不走腾讯/东财 push2。
