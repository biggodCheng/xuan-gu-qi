# 行业资金流排行榜（东财行业板块 · 今日）

抓取东方财富行业板块当日主力资金净流入快照，作为**复盘观察参考**。

> ⚠️ 资金流入 ≠ 买点。主力净流入反映当日资金方向，高位放量流入常是接力/出货。须结合 fupan 复盘与 qsht 选股体系的趋势/回踩/市值/业绩纪律使用，避免追涨。

## 使用方式

输入 `/zijinliu` 触发。

## 执行步骤

1. 🔴 CHECKPOINT（运行前检查今日快照是否已存在）:
   ```bash
   ls .claude/skills/zijinliu/data/zijin_$(date +%Y-%m-%d).json 2>/dev/null
   ```
   - 已存在 → 🛑 STOP，提示"今日资金流快照已抓取，重跑会覆盖"，询问确认；用户确认后加 `--force` 重跑。
   - 不存在 → 继续。

2. 确认依赖（首次）:
   ```bash
   cd .claude/skills/zijinliu && pip install -r requirements.txt
   ```

3. 运行:
   ```bash
   cd .claude/skills/zijinliu && python main.py
   ```
   > 仅 requests，无 Playwright，约 2–5 秒。可选参数：`--top 20 --outflow-top 10 --per-end 100 --date YYYY-MM-DD --force`。

4. 脚本会：抓东财行业板块资金流（流入端降序 + 流出端升序，各 Top100）→ 端内去重（消除银行/银行Ⅱ 同行业多层级重复）→ 存 `data/zijin_<date>.json` → 终端打印流入 Top20 + 流出 Top10。

5. 读取 `data/zijin_<date>.json` 或终端摘要向用户展示，并提醒"高流入 ≠ 买点"。

## 字段说明

| 字段 | 含义 |
|---|---|
| 行业 name | 东财行业板块名（已去重，保留一级名） |
| 涨跌% change_pct | 板块当日涨跌幅 |
| 主力净流入(亿) main_net_yi | 主力（超大单+大单）净流入额，÷1e8 转亿 |
| 占比% main_pct | 主力净流入 / 板块成交额，排除体量偏差（双口径之一） |
| 超大单(亿) super_large_net | 超大单净流入额 |

## 双口径解读

- **主力净流入额**（默认排序）：看绝对吸筹/出货量，偏向大体量行业。
- **净流入占比**：看相对进攻强度，排除体量偏差（小行业占比可能很高）。
- 两者结合：额大且占比高 = 资金实质性进场；额大但占比低 = 仅因体量大。

## 边界条件

| 触发 | 处理 |
|---|---|
| 非交易日 | 接口返回上一交易日数据，正常抓取，date 标注实际数据日 |
| push2delay 偶发空响应 | 3 轮退避重试 |
| 接口被封/改版 | 报错；重跑 `python probe_fs.py` 诊断字段/fs 是否变化 |
| 今日快照已存在 | CHECKPOINT 询问，`--force` 覆盖 |
| 盘中运行 | 资金流为盘中实时值（会随盘变化），复盘建议收盘后跑 |

## ❌ 不要做

- 不要把主力净流入当买入信号（高流入常是高位接力/出货窗口）
- 不要追多时间窗口/概念板块/个股（本 skill 仅行业·今日·双口径）
- 不要为资金流做 fallback 数据源（各源"主力"口径不一，混用易乱）

## 局限

- 资金流数据来自东财 Level-1 估算（超大单/大单按成交单金额切分），非真实逐笔，属估算值
- 仅今日快照，不反映多日持续性（持续流入须对比历史快照）
- "主力"定义按东财口径，与其他平台不可直接横向比较
