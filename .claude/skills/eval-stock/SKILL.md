# eval-stock — 个股定点体检器

## 用途
对**指定的一两只股票**快速评估其在 qsht 选股体系各维度的成色。区别于 qsht-agent（全市场扫描、10-25 分钟、落盘大报告），本工具是秒级定点体检、终端直接输出。

## 运行
```bash
python .claude/skills/eval-stock/main.py <代码或名称>[,...]
```
示例：`python main.py 深科技,有研新材`、`python main.py 000021`、`python main.py 600206`。

代码与名称都能传；名称经东方财富 searchapi + 新浪行情解析为代码。

## 7 维度（阈值与 qsht 各子 skill 默认一致）
1. **趋势新高**（eval-stock 放宽）：近 20 交易日内任一天创该日前 100 日新高 → 通过。标注"今日新高 / 近N日前创新高 / 距高点-X%"。
2. **近 15 天涨停**：按板块阈值（主板 9.5% / 科创创业 19.5% / 北交所 29.5%）。
3. **缩量回踩（策略1）**：最后一次涨停后连续 close<zt_close 且 volume<prev×0.8，≥2 天。
4. **市值**：总市值 < 500 亿。
5. **Q2 业绩展望**：复用 q2zhanwang（一季报同比势头 + 营收-净利背离推断）。
6. **赛道**：复用 sidasaidao（四大赛道）。
7. **承接**（参考维度，不进漏斗）：3 信号 — 下跌缩量(量比<0.8) / 不破支撑(近10日低点≥回调前20日低点×0.98) / 砸盘收回(长下影占振幅≥50%)。命中≥2 ✅有力 / =1 ➖一般 / =0 ❌弱（"一句话"加"承接偏弱，等买点"软警示）。数据源=日K，无新依赖。

## 与 qsht-agent 的差异
- 第①步：eval-stock 用"近一月新高"（体检语义，看趋势是否还在）；**qsht-agent 用"今日新高"**（选股语义，要今日创新高的票）。同一只票可能这里①通过而 qsht 当日筛不中——这是设计意图。
- 其余维度阈值完全一致。

## 输出示例
```
深科技(000021) · 电子系统组装 · 数据截至 2026-07-08 · 最新 51.13
─────────────────────────────────────────────
① 趋势新高    ✅  近 6 日前 2026-06-30 创 100 日新高
② 近15天涨停   ✅  2 次（06-24、06-29）
③ 缩量回踩    ✅  2026-07-03 起 2 天，量比 0.70
④ 市值<500亿   ❌  805 亿 / 流通 805 亿
⑤ Q2展望     ➖  中性（净利 +35% / 营收 +11%）
⑥ 赛道       ✅  AI硬件和基础设施、大工业、大能源、光和电子 主 AI硬件和基础设施(中)
⑦ 承接        ✅  有力（3/3：缩量、不破支撑、砸盘收回）
─────────────────────────────────────────────
qsht 漏斗判定：不达标 — ④ 市值<500亿 淘汰（市值未过）
一句话：非体系标的，不建议追（④ 市值<500亿 淘汰（市值未过）；大票）
```

- 灯标：`✅` 通过 / `❌` 不通过 / `➖` 中性（Q2，或 ⑦承接 一般/数据不足）。
- 漏斗按 ①→②→③→④ 串联，任一步淘汰即整体"不达标"，并指出在哪步淘汰；⑤⑥⑦ 为参考维度，不参与淘汰。

## 边界条件

| 触发条件 | 处理 |
|---|---|
| 股票代码/名称不存在 | 标"未找到股票"，不阻断其他股票 |
| Q2/赛道模块加载失败 | 维度⑤⑥标"数据不可用"，其余维度正常输出 |
| 个股取数失败（K线/市值） | 标"取数失败"，不阻断其他股票 |
| 盘中运行 | 标注"盘中未收盘"，数据为实时价 |
| 多只传入 | 逐只独立评估，互不影响 |

## ❌ 反例黑名单

| 不要 | 原因 | 正确做法 |
|---|---|---|
| 把体检当买卖建议 | 体检是成色评估，非买点信号 | 结合 qsht 选股纪律 + 自身策略决策 |
| 市值淘汰后仍当体系标的 | 漏斗④淘汰即不达标 | ④市值<500亿淘汰 = 大票，非体系标的 |
| 混淆体检语义与选股语义 | eval-stock①用近一月新高（看趋势在不在），qsht①用今日新高（选今日创新高） | 同一只票可能这里通过而 qsht 当日筛不中——是设计意图 |
| 忽视灯标 ➖（Q2 中性） | 中性≠没问题 | 看 signals 细分方向，confidence=低则结论打折 |
| 承接弱就弃单 | 承接是买点维度非成色筛选，承接弱=等买点 ≠ 不买 | 趋势在但承接弱 → 等买点；⑦为参考维度不参与漏斗淘汰 |

## 注意
- 数据截至最新交易日收盘；盘中运行会标注"盘中未收盘"。
- 单只取数失败不阻断其他股票（标"取数失败"并继续）。
- 纯终端输出，**不落盘、不写其他 skill 的 data 目录**（Q2/赛道经 importlib 内存复用，无副作用）。
- 数据源：新浪日K(不复权) + 腾讯qt市值 + 东方财富财报 + 新浪/东财名称行业 + sidasaidao 赛道库。
- ⚠️ K线用新浪日K(CN_MarketData.getKLineData,不复权),100日窗口内除权影响有限;腾讯qt市值(qt.gtimg.cn)取总/流通市值。(2026-07-16 曾因腾讯WAF迁新浪;2026-07-18 实测腾讯日K已恢复,但沿用新浪统一数据源。)
