# 创新高选股器

A股收盘后筛选创100个交易日新高的股票。

## 使用方式

输入 `/chuangxingao` 触发执行。

## 执行步骤

1. **🔴 CHECKPOINT · 运行前先检查当天数据是否已存在**：
   ```bash
   ls .claude/skills/chuangxingao/data/$(date +%Y-%m-%d).json 2>/dev/null
   ```
   - 若文件**已存在**：🛑 STOP — 提示用户"今日数据已存在"（可用 Read 查看其 `count`），重新运行会**覆盖**已有结果并耗时约 10-20 分钟。**询问用户是否确认重跑，确认前不要进入步骤 3**；若用户不重跑，直接读取已有文件展示结果即可。
   - 若**不存在**：继续步骤 2。

2. 确认依赖已安装：
   ```bash
   cd .claude/skills/chuangxingao && pip install -r requirements.txt
   ```

3. 运行选股脚本：
   ```bash
   cd .claude/skills/chuangxingao && python main.py
   ```
   > 脚本运行中会打印进度（每 500 只刷新一次），全程约 10-20 分钟，请耐心等待。

4. 脚本会：
   - 获取全 A 股当日行情
   - 逐个获取历史数据（约 10-20 分钟；优先腾讯财经 API，返回条数过少如北交所 920xxx 仅 1 条时自动回退新浪 API 取完整历史）
   - 计算哪些股票创100日新高（**历史不足 60 个交易日的股票跳过、不纳入判定**——避免数据残缺导致新低股被误判）
   - 结果保存到 `data/YYYY-MM-DD.json`

5. 读取输出文件，向用户展示结果摘要：
   - 创新高股票总数
   - 输出文件路径
   - 列出前10只股票（代码、名称、收盘价、100日最高价）
   - 若脚本日志提示跳过了历史数据不足的股票，告知跳过数量（解释 count 为何可能偏小）

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 非交易日（周末/节假日） | 脚本提示"未获取到行情数据，可能是非交易日"，告知用户改日再试 |
| 网络请求超时 | 脚本有重试机制；若仍失败，提示"网络异常，请稍后重试" |
| 结果为空（0只创新高） | 属正常情况，提示"今日无股票创100日新高" |
| 已有当天数据文件 | 提示用户"今日数据已存在"，询问是否覆盖 |
| 历史数据不足的股票（如部分北交所，腾讯数据源只返回极少几条残缺数据） | 自动回退新浪取完整历史；若仍不足 60 个交易日则跳过，**不纳入新高判定**——避免无足够历史可比的大跌股被误判为新高 |

## 流程链

本 skill 是选股流程的**第一步**，输出供下游 skill 使用：
- `/zhangting` → 从创新高中筛选涨停股
- `/shizhi` → 从涨停股中按市值筛选
- `/suolianghuicai` → 从涨停股中筛选缩量回踩
