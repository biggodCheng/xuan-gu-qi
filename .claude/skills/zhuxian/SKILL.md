# 主线板块筛选器

从A股概念板块中选出满足以下条件的 Top 10 主线板块：
1. 趋势上涨（均线多头排列）
2. 不断破新高（higher highs）
3. 低点不断抬高（higher lows）
4. 有长期上涨逻辑（区间涨幅大）

## 使用方式

输入 `/zhuxian` 触发执行。

用户可通过自然语言指定数量，如"给我前5个主线板块"→ 自动设置 `--top 5`。

## 执行步骤

1. 确认依赖已安装：
   ```bash
   cd .claude/skills/zhuxian && pip install -r requirements.txt
   ```

2. 如果用户指定了数量，提取为 `--top` 参数。

3. **检查是否已有当天数据**：如果 `data/zx_YYYY-MM-DD.json` 已存在，提示用户"今日数据已存在"，询问是否使用 `--force` 覆盖。用户确认后再执行。

4. 运行筛选脚本：
   ```bash
   cd .claude/skills/zhuxian && python main.py --top <N>
   ```

5. 脚本会：
   - 获取所有概念板块列表（约300+个，东方财富数据源）
   - 并发获取每个板块的120日K线数据（20线程，约1-2分钟）
   - 对每个板块做趋势分析（均线排列、高低点趋势、综合打分）
   - 按趋势得分排名，选出 Top N
   - 结果保存到 `data/zx_YYYY-MM-DD.json`

6. 读取输出文件，向用户展示结果摘要：
   - 主线板块数量
   - 输出文件路径
   - 列出所有板块（排名、名称、代码、趋势得分、收盘价、20日涨幅、原因）

7. **结果解读**：趋势得分含义参考：
   - 85+ 分：强势主线，多指标共振
   - 70-85 分：趋势良好，可关注
   - 60-70 分：偏弱，谨慎参考

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 非交易日（周末/节假日） | 东方财富API仍返回最近交易日的数据，脚本正常运行 |
| 网络请求超时 | 脚本有重试机制；若大面积失败，提示"网络异常，请稍后重试" |
| 结果不足10个 | 正常输出实际数量，提示"当前满足条件的板块较少" |
| 已有当天数据文件 | **暂停，询问用户**是否覆盖（除非明确指定 `--force`） |
| 板块K线数据不足60天 | 跳过该板块（数据不足以做趋势判断） |
| 无任何板块通过筛选 | 提示"当前市场无明显主线板块，可稍后再试" |

## 独立性

本 skill 是独立的，不依赖其他 skill 的输入。它是选"板块"而非"个股"。

可作为选股流程的**前置步骤**：先通过本 skill 选出主线板块，再从主线板块中筛选个股。
