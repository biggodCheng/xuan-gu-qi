# 主线板块筛选器

从A股概念板块中选出满足以下条件的 Top 10 主线板块：
1. 趋势上涨（均线多头排列）
2. 不断破新高（higher highs）
3. 低点不断抬高（higher lows）
4. 有长期上涨逻辑（区间涨幅大）

## 使用方式

输入 `/zhuxian` 触发执行。

用户可通过自然语言指定数量，如"给我前5个主线板块"→ 自动设置 `--top 5`。

## 执行步骤

1. 确认依赖已安装：
   ```bash
   cd .claude/skills/zhuxian && pip install -r requirements.txt
   ```

2. 如果用户指定了数量，提取为 `--top` 参数。

3. **🔴 CHECKPOINT · 检查是否已有当天数据**：
   ```bash
   ls .claude/skills/zhuxian/data/zx_$(date +%Y-%m-%d).json 2>/dev/null
   ```
   - 若**已存在**：🛑 STOP — 提示用户"今日数据已存在"，询问是否用 `--force` 覆盖（重跑约 100~300 秒，取决于东财源当日速度）。**用户确认前不要进入步骤 4**。
   - 若**不存在**：继续步骤 4。

4. 运行筛选脚本（依步骤 3 结果选择命令）：
   ```bash
   # 首次运行（当天无数据）：
   cd .claude/skills/zhuxian && python main.py --top <N>
   # 用户确认覆盖已有数据时，追加 --force：
   cd .claude/skills/zhuxian && python main.py --top <N> --force
   ```

5. 脚本会：
   - 获取所有概念板块列表（东财 push2delay，约 431 个概念板块，已剔 64 个风格/元板块黑名单）
   - 对每个板块取**全部成分股**，读本地招商证券 vipdoc 个股日K，等权聚合为板块合成K线（10线程，约 100~300 秒，取决于东财源当日速度）
   - 对每个板块做趋势分析（均线排列、高低点趋势、综合打分，得分<50 不入选）
   - 按趋势得分排名，选出 Top N
   - 结果保存到 `data/zx_YYYY-MM-DD.json`
   - **盲区**：脚本只扫**概念板块（t:3）**，行业板块（t:2，如电力 BK0428 / 化学制药 BK0465）不扫；判行业方向需手动补扫 t:2。

6. 读取输出文件，向用户展示结果摘要：
   - 主线板块数量
   - 输出文件路径
   - 列出所有板块（排名、名称、代码、趋势得分、收盘价、20日涨幅、原因）

7. **结果解读**：趋势得分含义参考：
   - 85+ 分：强势主线，多指标共振
   - 70-85 分：趋势良好，可关注
   - 60-70 分：偏弱，谨慎参考

## 数据源

v3（2026-07 定型）：**东财板块成分股 + 本地 vipdoc 全成分聚合**。

- **板块列表 + 当日涨跌**：东财 push2delay clist（`fs=m:90+t:3+f:!50`，概念板块），板块代码为东财 `BKxxxx`（约 431 个，已剔 64 个风格/元板块黑名单）。
- **板块合成日K**：东财拉板块**全部成分股**代码 → 本地招商证券 vipdoc 读个股日K（不复权）→ 全成分等权聚合。**非真实板块指数**，但全成分聚合 ≈ 真实板块感受。
- **字段口径（2026-07-23 修复）**：`close`/`change_pct` 与均线/涨幅**同源**（聚合均价口径，几十元量级），可互相对照读数；东财真实板块指数点位/涨跌另存 `index_close`/`index_change_pct` 备查（几千点量级，**勿与 close 混用**）。
- **盲区**：只扫概念板块（t:3），行业板块（t:2，如电力/化学制药）不扫，判行业方向需手动补扫。
- 个股日K不复权，聚合会稀释单只除权跳空（跨季/回测级精度需用新浪 qfq）。

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 非交易日（周末/节假日） | 本地 vipdoc 返回最近交易日数据，脚本正常运行 |
| 网络请求超时 | 脚本有重试机制；若大面积失败，提示"网络异常，请稍后重试" |
| 结果不足10个 | 正常输出实际数量，提示"当前满足条件的板块较少" |
| 已有当天数据文件 | **暂停，询问用户**是否覆盖（除非明确指定 `--force`） |
| 板块K线数据不足60天 | 跳过该板块（数据不足以做趋势判断） |
| 无任何板块通过筛选 | 提示"当前市场无明显主线板块，可稍后再试" |

## 独立性

本 skill 是独立的，不依赖其他 skill 的输入。它是选"板块"而非"个股"。

可作为选股流程的**前置步骤**：先通过本 skill 选出主线板块，再从主线板块中筛选个股。
