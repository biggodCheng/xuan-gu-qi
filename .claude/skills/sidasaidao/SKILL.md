# 四大赛道查询器

查询一只 A 股是否属于四大赛道，返回所属赛道及匹配详情。

## 四大赛道概览

中国 A 股的核心产业投资可以归纳为四大赛道，它们之间有上下游关联：

1. **大工业**：汽车、机器人、无人机、军工航天、材料、通信、先进制造
2. **大能源**：风光水火氢核、储能、特高压、电网、碳中和
3. **光和电子**：光通信、光模块、电子材料、PCB、光纤、高速铜连接
4. **AI 硬件和基础设施**：芯片、半导体、服务器、液冷、算力、AI 应用

## 使用方式

输入 `/sidasaidao <股票代码或名称>` 触发执行。

例如：
- `/sidasaidao 600519` — 按股票代码查询
- `/sidasaidao 比亚迪` — 按股票名称查询
- `/sidasaidao 002594` — 比亚迪的代码

## 执行步骤

1. 确认依赖已安装：
   ```bash
   cd .claude/skills/sidasaidao && pip install -r requirements.txt
   ```

2. 运行查询脚本：
   ```bash
   cd .claude/skills/sidasaidao && python main.py "<股票代码或名称>"
   ```

3. 脚本会：
   - 如果输入是名称，先搜索对应的股票代码
   - 从东方财富 API 获取该股票的**行业分类**和**所属概念板块**
   - 将行业/概念与四大赛道的关键词库进行匹配
   - 输出该股票属于哪个/哪些赛道，以及匹配到的具体标签

4. 读取输出，向用户展示：
   - 股票基本信息（代码、名称、行业）
   - 所属赛道及匹配到的关键词
   - 赛道之间的关联说明（如果涉及多个赛道）
   - 不属于任何赛道时，说明原因

## 边界条件

| 场景 | 处理方式 |
|------|---------|
| 股票代码/名称不存在 | 提示"未找到该股票"，建议检查代码或名称 |
| 股票不属于任何赛道 | 提示"该股票当前不属于四大赛道"，并列出其行业和概念供参考 |
| API 请求失败 | 提示"数据获取失败"，建议稍后重试 |
| 股票属于多个赛道 | 列出所有匹配的赛道，说明跨赛道的产业链关系 |

## ⚠️ 匹配机制与局限

### 匹配原理
脚本用股票的**行业 + 概念板块**标签，与四大赛道关键词库做子串匹配（关键词在标签里、或标签在关键词里即命中）。一只股票通常挂多个概念，因此**常同时命中多个赛道**。

### 已知局限（解读结果前必读）

| 现象 | 原因 | 正确解读 |
|---|---|---|
| 命中多个赛道 | 一只股常挂多个概念 | **核心看 industry 命中的赛道**（confidence=高即主业）；industry 未命中的赛道代码已降权为"中"，属附带 |
| `cross_track_note` 啰嗦 | 命中 ≥3 赛道时拼接所有赛道对 | 关注 note 点名的高分赛道对，忽略附带项 |
| confidence="高"但主业不符 | 宽泛词命中数够多即给"高" | 结合 `industry` 字段判断主业，命中数仅供参考 |

### 解读操作流（多赛道命中时按此过滤）

1. 先看 `industry` 字段确定**主业**（如"乘用车" → 主业是汽车）
2. 命中赛道中，保留与主业直接相关的（汽车 → 大工业）
3. 其余 confidence="高" 的赛道，仅当 `industry` 能佐证才计入核心（车厂的"电池"概念可佐证大能源）
4. 仅靠宽泛词（IDC / 出海 / 半导体 / 矿）触发的赛道标记为**边缘命中**，不计入核心
5. 例：比亚迪 `industry`="乘用车" → 核心赛道 = 大工业（主业）+ 大能源（电池佐证）；AI 硬件 / 光和电子为边缘命中

### ❌ 不要做

- 不要把所有命中赛道都当核心赛道——一只车厂可能因"半导体/IDC"概念被标进 AI 硬件，但主业不是
- 不要仅凭 confidence="高" 就判断投资价值——它是关键词命中度的反映，非价值判断
- 不要因非交易日认为数据不变——概念板块随行情动态增减，结果可能波动

## 赛道之间的关联

四大赛道并非完全独立，它们之间有上下游关联：

- **大工业** 的上游需要 **光和电子**（PCB、芯片、传感器）和 **大能源**（电池、电机）
- **大能源** 的下游连着 **大工业**（电车、机器人、无人机）
- **光和电子** 是 **AI 硬件** 的上游（光芯片、光模块）
- **AI 硬件** 的上游是 **光和电子**（芯片）和 **大能源**（算电协同）
- **大能源** 的光和电子部分涉及光通信和电子材料
