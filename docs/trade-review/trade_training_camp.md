## 📅 四周阶段计划

### 第 1 周 · 止血周（不亏就是赢）
**唯一目标：把三把放血的刀拔掉。**
- [ ] 零补仓：任何浮亏单禁止加仓，加仓唯一合法前提=浮盈+趋势延续
- [ ] 单笔仓位 ≤ 5 万（建议 1-3 万）
- [ ] 连续亏损 2 笔 → 强制停手一天
- [ ] **本周允许不交易**。看盘，但不动手，能忍住就是毕业。

**考核**：周末跑 `trade_review`，补仓次数 = 0、大单占比 < 10% 即过关。

### 第 2 周 · 择时周（学会"不做"）
**唯一目标：让市况工具替你踩刹车。**
- [ ] 每天开盘前 9:00 跑 `market_regime`
- [ ] 🔴 退守市 → **全天不开新仓**，只处理存量止损/止盈
- [ ] 🟡 防守市 → 仓位减半(≤2.5万)，每周≤5笔，连亏1笔就停半天
- [ ] 🟢 进攻市 → 才允许正常仓位
- [ ] **记住**：你历史 80% 的大亏发生在退守市。本周练的是"市况不对就坐着"。

**考核**：退守市那天你开了几笔新仓？必须是 0。

### 第 3 周 · 选股周（只做对的票）
**唯一目标：只用准入清单筛票，月交易降到 ≤15 笔。**
- [ ] 每笔买入前，准入清单 8 条**逐项打勾**，少一条都不买
- [ ] 只做 `qsht-agent` 流水线 + `chuangxingao`/`qibao` 选出的票（你项目里的工具就是为这个建的）
- [ ] 高价股(>25元)、缩量阴跌股、冷门票 → 一律不碰
- [ ] **少而精**：本周目标 3-5 笔，每笔都是清单全满足。

**考核**：实际交易笔数 ≤ 5，且每笔都附准入清单打勾记录。

### 第 4 周 · 固化周（变成本能）
**唯一目标：不看清单也能做到（肌肉记忆）。**
- [ ] 前三周的规则继续执行
- [ ] 每笔交易写完整日志（买入逻辑/止损位/卖出原因/复盘对错）
- [ ] 周末跑 `trade_review`，看红绿灯变化
- [ ] **如果红绿灯有任何一项翻绿，恭喜毕业。** 没翻绿，再训一个月。

**考核**：红绿灯 ≥3 项绿 = 毕业。否则延长。

| 时间 | 科目 | 工具/动作 |
|---|---|---|
