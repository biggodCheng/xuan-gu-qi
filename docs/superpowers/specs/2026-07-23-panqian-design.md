# panqian(盘前外部温度计)— 设计文档

> 日期:2026-07-23 ｜ 状态:已确认,待实现 ｜ 产出方式:brainstorming
> skill 目录:`.claude/skills/panqian/`

## 1. 背景与定位

### 1.1 要解决的问题

现有体系(fupan / market_regime / zhuxian / qsht 系列)全部聚焦 **A 股内部数据**,且所有每日类工具(fupan)都在 **盘后** 运行。体系缺失两个象限:**「向外·全球」** 与 **「盘前」**。A 股当日开盘与早盘走势,相当程度上受隔夜美股、A50 期货、中概股、汇率/大宗、国际重大事件等外生变量驱动,而目前没有任何工具结构化采集这些信号。

### 1.2 核心定位:采集器,非预测器

`panqian` 是 **A股盘前外部信号采集器**——盘前自动采集隔夜外盘 + 国际事件,产出「盘前外部温度计.md」。

**只做两件事**:
1. 陈列客观隔夜事实(美股/A50/中概/汇率/大宗/事件);
2. 附轻量"历史经验映射"(静态整理,非回测)。

**明确不做**:不预测今日涨跌、不给开盘方向结论、不给买卖建议。开盘方向由盘口决定,不由此报告定。

### 1.3 与体系的纪律对齐(关键)

用户实盘复盘记录:2024-09~2025-12 共 15 个月亏损 18.4 万,核心病灶是 **过度交易 + 不止损 + 赌开盘**(追涨停次日高开是典型大亏姿势)。因此本 skill 必须严守:

- **不预测涨跌**——一个"告诉你今天高开/要涨"的工具会直接喂给过度交易本能。
- 与 fupan 的设计哲学一致:"不预测,只做信号触发才动手的应对预案"。
- 用工具拿客观数据,脑力留给主观研判(盘前研判由人工 checkpoint 填写,报告不给结论)。

## 2. 在选股/复盘体系中的位置

更新 fupan 现有的"职责边界表":

| 工具 | 职责 | 时间维度 | 数据方向 | 关系 |
|------|------|---------|---------|------|
| **panqian(新)** | 隔夜外部信号 → 盘前温度计 | **盘前** | **向外·全球** | fupan 对照引用 |
| fupan | A股内部结构 → 次日剧本 | 盘后 | 向外·境内 | 读 panqian 做对照 |
| market_regime | A股市况总开关 🔴🟡🟢 | 盘中/盘后 | 向内 | fupan 复用 |
| trade_review.py | 周复盘,盯账户纪律 | 周末 | 向内·账户 | 互补 |

### 闭环(方案A的核心价值)

```
盘前 panqian(外部环境预判) → 盘中实际开盘/走势 → 盘后 fupan 对照(隔夜信号灵不灵) → 次日剧本
```

盘后"对照"环节逼用户客观记录"隔夜信号到底兑现没有",防止事后归因(对了吹、错了忘),并沉淀"哪些隔夜信号对 A 股真有效"的经验。

## 3. 采集范围(4 维)

| 维度 | 内容 | 对 A 股的意义 |
|------|------|--------------|
| 1. 美股三大指数 | 纳指/标普/道指隔夜收盘涨跌、振幅、纳指vs道指结构 | 隔夜定调,风险偏好 |
| 2. A50 期货 + 中概股 | 富时A50(夜盘+早盘)、纳斯达克金龙指数、热门中概 | **A 股开盘最强领先指标** |
| 3. 汇率 + 大宗商品 | 离岸人民币、沪铜/伦铜、金、油、铁矿 | 板块映射(有色/石化/航空等) |
| 4. 国际重大事件 | 地缘/美联储/重要经济数据/重大会议 | 风险偏好冲击 |

## 4. 数据源方案

### 4.1 重要前提:接口均为候选,待实测

下列外盘接口在本项目中 **均未实测过**(项目现有数据源全是 A 股内部)。所有接口标为 **候选**,实现阶段必须逐个实测可用性再定型(对齐用户记忆中"别用未实测接口名当确定事实"的教训)。第 10 节集中列出待实测清单。

### 4.2 统一信源策略

优先 **新浪体系**(项目已在用新浪 A 股,直连可用、无需代理、请求 headers 处理可复用 fupan 的实现),Yahoo Finance(走本机 clash 代理 7897)做 fallback,东方财富全球指数做最后降级。新闻维度例外,为独立新增信源。

### 4.3 维度1 · 美股三大指数

| 采集项 | 候选接口(待实测) | 降级链 |
|--------|------------------|--------|
| 纳指 IXIC / 标普 GSPC / 道指 DJI 收盘涨跌幅、振幅 | 新浪美股 `hq.sinajs.cn/list=gb_ixic,gb_inx,gb_dji` → Yahoo `^IXIC/^GSPC/^DJI`(代理7897) → 东财全球指数 | 三源逐级降级 |

重点输出:收盘涨跌幅、纳指 vs 道指(科技 vs 传统,反映风险偏好)、盘中振幅。任一指数失败标 ⚠️ 不阻断其他指数。

### 4.4 维度2 · A50 期货 + 中概股(关键维)

| 采集项 | 候选接口(待实测) | 降级链 |
|--------|------------------|--------|
| 富时 A50 期货(新交所,代码 CN)隔夜+早盘 | 新浪期货 `hq.sinajs.cn/list=hf_CN` → 标⚠️(此维无可靠替代) | **A50 失败 = 关键缺失** |
| 纳斯达克金龙中国指数 HXC + 热门中概(阿里/京东/拼多多/百度/网易) | 新浪 `gb_hxc` + `gb_baba,gb_jd,gb_pdd,gb_bidu,gb_ntes` | 金龙失败 → 抓 top 中概股聚合 |

**A50 是本维核心**。A50 失败时报告顶部必须明示"缺 A50 信号,开盘预判可靠性下降",**不静默降级**——它对 A 股开盘指示性最强,缺失即实质性盲区。

### 4.5 维度3 · 汇率 + 大宗商品

| 采集项 | 候选接口(待实测) | 板块映射 |
|--------|------------------|---------|
| 离岸人民币 USD/CNH | 新浪外汇 `hq.sinajs.cn/list=fx_susdcnh` | 贬值→航空/造纸受损,出口链受益 |
| 沪铜/伦铜、沪金/COMEX金、WTI油、铁矿 | 新浪期货 `hf_cu,hf_gc,hf_cl` 等 | 铜涨→有色资源;油价→石化;金涨→避险 |

### 4.6 维度4 · 国际重大事件(最难)

**信源(自动抓权威信源)**:

1. **财联社电报** — 非官方 API `cls.cn/nodeapi/updateTelegraphList`,返回 JSON(字段含 title/content/ctime,重要度字段待实测)。覆盖实时快讯。
2. **金十财经日历** — `jin10.com` 财经日历(强反爬,待实测)。覆盖重要数据/央行决议,有星级标记。

**筛选规则**(解决"几百条电报怎么过滤"):

- **时间窗**:昨夜 18:00(北京)~ 今日开盘前——覆盖美股盘前+盘中+盘后。
- **重要性过滤**:金十按星级(★★★优先:非农/CPI/美联储FOMC/欧央行);财联社按重要度字段(若有)或关键词(美联储/加息降息/CPI/非农/地缘/冲突/制裁/关税/财报/央行/黑天鹅)。
- **去重合并**:同一事件两源都报则合并一条。
- **输出**:top 5–8 条,按时间倒序 + 重要性排序。
- **兜底**:报告底部固定留"⚠️ 若有重大突发未抓到(接口被封/漏抓),手动补充"——自动抓不可能 100% 可靠,必须给人工兜底口子。

### 4.7 失败处理统一原则(对齐 fupan 铁律)

- 各维独立,**一维失败不阻断其他维**,该维标 ⚠️。
- **关键维缺失(A50/美股)→ 报告顶部明示盲区**,不静默;非关键维单项缺失 → 该行标 ⚠️。
- **不过期数据**:美股数据校验"最近美股交易日收盘日期",拒绝缓存/陈旧数据。
- 信源全失败(极端)→ **停止执行 + 打印各源失败原因**(对齐 fupan"宁停勿用过期数据")。

## 5. 输出报告结构

报告存 `.claude/skills/panqian/output/{日期}.md`。模板(以下数据为**示意**,非真实):

````markdown
# 盘前外部温度计 · YYYY-MM-DD(周X)

## 0. 隔夜定调(一句话)
外部环境:[偏暖/中性/偏冷/恐慌] | 信号强度:[强/中/弱]
> ⚠️ 这是"外部环境"描述,不是"今天涨跌"预测。开盘方向由盘口决定,不由此报告定。

## 1. 美股隔夜(定调)
| 指数 | 收盘 | 涨跌 | 备注 |
|------|------|------|------|
| 纳指 | - | -1.8% | 科技领跌 |
| 标普500 | - | -1.2% | |
| 道指 | - | -0.9% | |
结构:纳指弱于道指(科技抛售)｜振幅:纳指 2.1%

## 2. A50期货 + 中概(A股开盘风向标)
A50期货:-( -0.6%)｜[夜盘/早盘]｜→ 历史上对应A股低开约 -0.3~-0.6%
金龙中国指数:-( -2.1%)｜中概普跌
热门中概:阿里 -2.5% / 京东 -3.1% / 拼多多 -2.0% / 百度 -1.8%

## 3. 汇率 + 大宗(板块映射)
离岸人民币:7.28(+0.2%贬值)｜贬值压力
沪铜 +1.5%(有色利好)｜COMEX金 +0.3%(避险)｜WTI油 -2%(石化承压)

## 4. 国际重大事件(昨夜18:00~今晨)
1. [★★★] 美联储7月FOMC纪要偏鹰(财联社 02:30)
2. [★★★] 美国当周初请失业金超预期(金十 20:30)
3. [★★] 中东局势再度紧张(财联社 23:15)
> ⚠️ 若有重大突发未抓到,手动补充在此。

## 5. 历史经验映射(经验·非预测)
| 隔夜信号组合 | 历史经验(静态整理,非回测) |
|---|---|
| 纳指跌>1.5% & A50跌>0.5% | A股低开概率较高,但低开高走 vs 低开低走看量能 |
| 避险急升(金涨+VIX涨) | 防御板块(电力/医药/高股息)相对抗跌 |
| 人民币急贬 | 北向流出压力,核心资产承压 |
> 经验法则,非今日必然;辅助研判,不据此下单。

## 6. 你的盘前研判 [⛔ CHECKPOINT · 人工填写]
- 今日最值得警惕的隔夜信号:____
- 受益/受损板块初判:____
- 盘前纪律自检:[ ]不赌开盘 [ ]不追高开 [ ]等盘口信号

## 取数质量
美股[✓/⚠️]｜A50[✓/⚠️]｜中概[✓/⚠️]｜汇率[✓/⚠️]｜大宗[✓/⚠️]｜新闻[✓/⚠️]
````

**设计要点**:第0步定调但标注"非涨跌预测"(护栏);第5步映射标注"非预测";第6步人工 checkpoint(对齐 fupan 第3/4步);底部取数质量诚实标注。

## 6. 与 fupan 的联动(对照闭环)

fupan 盘后跑时,读 `.claude/skills/panqian/output/{今日}.md`,在第0步市况前插入**「第-1步·隔夜信号对照」**:

````markdown
## -1. 隔夜信号 vs 今日实际(读自 panqian 盘前温度计)
- 隔夜预示:外部偏冷(A50 -0.6% → 预示低开 -0.3~-0.6%)
- 今日实际:上证开盘 -0.4%｜收盘 +0.3%(低开高走)
- 兑现度:【兑现/部分兑现/背离】(脚本算)
- 教训沉淀:____(人工填,本次隔夜信号灵不灵)
````

- **兑现度**由脚本算(隔夜预示 vs 今日实际开盘/收盘),"教训沉淀"人工填(checkpoint)。
- panqian 当日报告不存在 → fupan 降级为"建议盘前先跑 /panqian",其余步骤照常(对齐 fupan 对 zhuxian 的降级处理)。
- fupan main.py **仅新增这一处读取 + 小节渲染,不改 fupan 原有 5 步逻辑**。

## 7. 运行方式

```bash
python .claude/skills/panqian/main.py              # 默认盘前跑(建议 7:30–9:00)
python .claude/skills/panqian/main.py --note "..." # 加备注
```

- **手动跑,不挂 cron**(对齐用户"不喜定时打扰、手动跑 /fupan 即可"的偏好)。
- **自包含**:`main.py` 自己拉 4 维数据,各维失败不阻断其他维。
- **目录结构**(对齐 fupan):`.claude/skills/panqian/{SKILL.md, main.py, output/{date}.md}`。
- **触发词**:"盘前"、"开盘前"、"看看隔夜"、"今早外盘"、"panqian"。

## 8. 边界条件

| 场景 | 处理方式 |
|------|---------|
| 关键维(A50/美股)全失败 | 报告顶部明示"外部信号缺失,研判可靠性低" |
| 新闻信源(财联社/金十)全失败 | 第4步 ⚠️"自动抓取失败" + 提示手动补充,其余维照常 |
| 美股数据 ≠ 最近美股交易日 | ⚠️"数据过期非昨夜",拒绝使用 |
| 盘中/美股未收盘时跑 | 提示"美股未收盘,建议盘前 7:30 后跑" |
| 非交易日跑 | 正常产出(标注最近交易日隔夜数据) |
| 信源全失败(极端) | **停止执行 + 打印各源失败原因** |

## 9. 反例黑名单(纪律护栏)

| 不要 | 原因 | 正确做法 |
|------|------|---------|
| 把第0步定调当涨跌预测 | 定调是"外部环境"不是"今天涨跌" | 开盘方向由盘口决定,报告只陈列外部事实 |
| 据"历史经验映射"下单 | 经验是统计倾向非必然 | 映射只辅助研判,据此下单=赌大小 |
| 据报告赌开盘(高开去追/低开去杀) | **这是用户 15 月亏 18.4 万的核心姿势** | 等盘口实际信号,信号触发才动手 |
| 跳过第6步研判 checkpoint | 报告不给结论,研判才是精华 | 填今日警惕信号 + 纪律自检 |
| 新闻自动抓没兜底就全信 | 自动抓可能漏重大事件 | 看 ⚠️ 或自知有突发时手动补充 |

## 11. 范围外(YAGNI·明确不做)

- **不做涨跌/开盘方向预测**(定位铁律)。
- **不做历史回测系统**(第5步映射是静态人工整理的经验,非程序化回测;若日后要做条件概率回测,另起子项目)。
- **不做自动交易/选股**(本 skill 只采集外部信号,不触发任何交易动作)。
- **不挂 cron 定时跑**(手动触发)。
- **不做富时 A50 以外的港股期货/日经等亚太市场**(MVP 聚焦 4 维;亚太可作为后续扩展)。
