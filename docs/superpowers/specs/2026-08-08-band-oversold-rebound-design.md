# 波段超跌反弹信号设计（band-oversold-rebound）

> 2026-08-08 · brainstorming 产出 · 与现有 chaodiefantan（超跌反抽，短线）并行的新策略

## 1. 背景与动机

**现象**：7 月 A 股跌一个月，8 月连涨 4 天（创业板 08-04 +5.64% / 08-05 +1.32% / 08-06 -0.55% / 08-07 续涨），但 chaodiefantan 连续 4 天 0 信号。用户质疑："跌了一个月反弹，怎么会没有超跌反弹股？"

**诊断（2026-08-07，08-04 反弹第 1 天拆解 4 条件漏斗，diagnose_zero.py）**：

```
有效样本 total           = 5318
条件1 含T日(代码当前)    = 37      ← 5318 只仅 37 只近5日跌>15%（8月初已反弹，急跌股少）
  +条件2 T-1长下影       = 1       ← 37 只急跌股仅 1 只有长下影！瓶颈在此
  +条件3 T-1缩量         = 1
  +条件4 阳包阴 → 信号   = 0
```

**根因**：瓶颈是**条件2（T-1 长下影）**。8 月反弹是 08-04 突发启动，T-1（08-03）仍在惯性阴跌收实体阴线、无承接预兆；策略要求"T-1 长下影"的渐进反转，抓不到"突发型反弹"。**非代码 bug、非数据问题，是策略形态与突发反弹的语义错配**。

**证伪**：初始猜测"条件1 含 T 日抵消跌幅"是次要因素——改用 T-1 口径条件1 从 37→106，但最终信号仍 0（瓶颈在条件2）。该猜测被数据否定。

**决策**：**不放宽现有 4 条件**（现有策略是回测正期望的：30 信号/胜率 40%/盈亏比 3.03/+3.27%；放宽会破坏基础，吸取 P1 教训）。改为**新增并行的波段超跌信号**，回测验证正期望后再上线。

## 2. 设计决策（brainstorming 已确认）

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 反弹启动判定 | **当日放量阳包阴**（去长下影） | 直击痛点（条件2 卡死 37→1），保留资金进场确认 |
| 超跌窗口 | **近 20 日**（≈一个月） | 对齐"7 月跌一个月"；月度级波段 |
| 超跌幅度 | 回测扫 20/25/30% | 数据定，不拍脑袋 |
| T-1 缩量 | 回测对比有/无 | 止跌确认，但可能过严 |
| 大盘开关 | 用户倾向"不要"；**回测对比有/无** | 用数据回答"无开关熊市会不会亏死"，不武断 |
| 落地形式 | **新独立 skill**，与 chaodiefantan 并行 | 语义不同（短线 vs 波段），独立触发/输出更清晰；数据层复用 |
| 上线闸门 | 回测正期望才落地 | 回测不过不硬上 |

## 3. 信号定义（判定函数 `is_band_rebound`）

由现有 4 条件改造：

| 条件 | 现有 chaodiefantan | 新波段信号 | 改动 |
|------|-------------------|-----------|------|
| 超跌 | 5 日跌>15% | **20 日跌>X%** | 月度级 |
| T-1 长下影 | 下影≥2×实体+3% | **删除** | 🎯 痛点 |
| T-1 缩量 | 前4日均量×0.8 | **回测对比有/无** | 数据定 |
| T日放量阳包阴 | 阳+收复前日开+破前日高+量×1.5 | **保留** | 资金进场 |

**精确定义（基础版 = 去长下影 + 去缩量）**：

```python
# bars 按日期正序, bars[-1]=T日, 需 >= 21 根
# 条件A: 近20日超跌
drop20 = (close[T] - close[T-20]) / close[T-20] * 100
if drop20 > -X:        return None      # X ∈ {20, 25, 30}
# 条件B: T日阳包阴
if not (close[T] > open[T] and close[T] > open[T-1] and high[T] > high[T-1]): return None
# 条件C: T日放量
if vol[T] < vol[T-1] * R: return None   # R ∈ {1.5, 2.0, 2.5}
# 条件D(可选, 回测对比): T-1缩量
#   vol[T-1] < mean(vol[T-5:T-1]) * 0.8
return {"drop20": drop20, "vol_ratio": vol[T]/vol[T-1], "stop_loss": low[T-1]}
```

**超跌口径疑点（待回测定）**：`drop20` 用 `close[T]/close[T-20]`（含 T 日反弹）会被反弹抵消一部分，但 20 日窗口长、T 日单日反弹抵消有限（如 20 日跌 25% + T 日涨 8% → 净 -17%）。回测**对比两种口径**：含 T 日 vs 不含 T 日（`close[T-1]/close[T-21]`），数据定。

## 4. 回测口径

复用 chaodiefantan/backtest 框架（signal_scan / simulator / dedup / market_cap），与老策略同口径对比。

| 维度 | 口径 |
|------|------|
| 数据 | 2018-01 ~ 2026-08 前复权日 K + 时变股本（data_loader） |
| 扫描 | 逐日逐股，对每个候选 T 日调用 `is_band_rebound` |
| 入场 | **T+1 开盘买**（避免未来函数） |
| 出场① | 固定持有 N 日（1/3/5/10/20），到期收盘卖 |
| 出场② | 止损版：持有期内破 T-1 最低 → 次日开盘止损 |
| 去重 | 同股 5 日内只留最早信号（dedup_signals） |
| 涨跌停 | T+1 开盘涨停买不进 → 跳过该信号（框架已有） |

**大盘开关（"有开关"组）**：复用 `chaodiefantan/screener/market_filter.py` 的 `is_market_crash`（三指数同步空头排列+近5日缩量），与现有 chaodiefantan 同口径；"无开关"组则不过滤。

**网格扫描组合**：超跌幅度 X(3) × 放量倍数 R(3) × T-1缩量(2) × 大盘开关(2) = 36 组参数；每组再 × 持仓 N(5) 看收益曲线。tail 优化后回测秒级，网格可行。

## 5. 成功标准（量化门槛）

1. **正期望**：T+1 开口口径下平均收益 > 0 且 `胜率 × 盈亏比 > 1`
2. **信号充足**：全期信号 ≥ 50，且分年分布不集中（现有 30 信号是"探索性小样本"前车之鉴）
3. 🎯 **熊市稳健**：2018、2022 两年单年期望 > -3%（量化回答"无开关熊市亏不亏"）
4. **分市值**：标出最有效市值带（对齐用户仓位偏好）
5. **对比现有**：同口径下新信号 vs 现有 chaodiefantan 的增量（信号数 / 期望 / 熊市稳健）

## 6. 决策规则（失败兜底，不硬凑）

- 全期正期望 + 熊市不暴亏 → ✅ 落地（最优参数组合 + 开关由数据定）
- 无开关在熊市暴亏 → ⚠️ 加大盘开关（用数据替我劝用户）
- 各组都不正期望 → ❌ 放弃，诚实报告，**禁止降阈值凑正期望**

## 7. 落地形式（分阶段）

| 阶段 | 做法 | 闸门 |
|------|------|------|
| **阶段 1** | 在 `chaodiefantan/backtest/` 加 `is_band_rebound` + 网格回测脚本，**不碰 chaodiefantan 主流程** | 回测跑通 + 报告 |
| **阶段 2** | 正期望则落地为新独立 skill（复用 fetcher/bridges，触发词与 chaodiefantan 区分） | 回测达标 |
| 命名 | 短线=chaodiefantan，波段=新 skill。具体名阶段 2 定 | — |

## 8. 实盘纪律对齐（设计灵魂）

对齐用户实盘复盘（2024-09~2025-12：负期望过度交易，15 月亏 18.4 万，胜率 46.7%/盈亏比 0.90/不止损/补仓摊平）：

- 🛑 **止损**：破 T-1 最低硬止损，**禁止补仓摊平**（切断亏损放大器）
- 💰 **止盈**：波段兑现（+8~15% 或破 5 日线走），反弹是兑现窗口不恋战
- 📊 **仓位**：单只 ≤ 10%
- ⚠️ **信号密度控制**：20 日超跌股多，信号会比短线密；若日均信号过多（喂养过度交易本能），加筛选门槛降密度
- ⚙️ **铁律**：只跑回测正期望的参数组合，回测不过不上线

## 9. 非目标（YAGNI）

- ❌ 不修改现有 chaodiefantan 的 4 条件（保持正期望基础，新策略独立并行）
- ❌ 不预测涨跌 / 不给买卖建议（信号参考，纪律由人执行）
- ❌ 阶段 1 不做 skill 化（回测验证优先，正期望前不投入 UI/触发词/文档）
- ❌ 不做 L2 资金流 / 分时维度（数据源只有日 OHLCV）
