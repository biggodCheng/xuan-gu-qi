## 1. 背景与动机

`fupan` 第3步「强势股拆解」依赖 `fupan_strong_scan.py` 出客观数据，但该模块**只输出零散的量能标签**（一字/烂板/爆量/缩量/封板/量比/振幅），**缺少判定首板属性最关键的三层维度**：

1. **K线形态**（横盘突破 vs 超跌反抽）— 完全没有
2. **板块联动**（独狼 vs 齐涨）— 完全没有
3. **首板属性综合归类**（情绪板/资金板/消息板）— 只有零散标签，无综合判定

**2026-07-29 复盘时的实测对照**催生了本工具：对当日两只 3 板票做人工三层判定——

| 票 | 形态 | 量能 | 板块 | 结论 |
|---|---|---|---|---|
| 华天酒店 000428 | 横盘1月→放量4.5倍突破3.20箱体 | 温和放量 | 独狼（酒店板块龙头才+1.6%） | 资金板苗头（但 Q2 偏负，游资型） |
| 兴欣新材 001358 | 从28.36跌29%→反抽到距高点-12.9% | 爆量4.3倍烂板 | 独狼（化工板块±2%） | 出货烂板（开板即崩风险） |

**关键洞察**：决定资金板 vs 烂板的差异在**形态 + 量能**（板块联动两只都是独狼、无区分度）。这三层判定是可量化的，应沉淀为工具，替代每次手工拉 K 线 + 查板块。

## 2. 目标与非目标

### 目标
- 提供底层 `pattern_label` 函数库，对任意 A 股输出「形态 / 量能 / 板块联动」三层客观标签 + 一个建议归类。
- 双入口：①被 `fupan_strong_scan` 调用给连板梯队前 N 只自动加标签；②独立单票 CLI。
- 建议归类明确标注「参考·需人工确认」，减轻研判但不替代人工。

### 非目标（重要，防重蹈覆辙）
- **不是选股过滤器，不过滤、不排序、不给买卖信号**。三层标签是**描述性**的，不是选股门槛。
  > 教训：[[chaodiefantan-nocap-p1-lesson]] 的 P1 翻车在于把描述性条件当选股门槛去优化。本工具的阈值是「标签描述参数」，**禁止**当作选股胜率优化的回测对象；阈值定 v1 初值后仅在「标签明显误判」时调整，不做胜率回测调参。
- **不替代 eval-stock**：eval-stock 管 qsht 体系的「趋势新高体检」，本工具管「首板属性/接力安全度」，定位不同。
- **不自动做最终买卖决策**：归类标「参考」，最终由 fupan 第3步人工研判。

## 3. 模块结构

```
scripts/
  pattern_label.py     【新·底层核心库，纯函数，零副作用，可独立测试】
  industry_map.py      【新·东财一级行业映射构建/加载】
  stock_pattern.py     【新·单票 CLI 入口】
  fupan_strong_scan.py 【改造·连板梯队前N只追加 pattern 标签】
data/
  industry_map.json    代码→东财一级行业 映射缓存
```

### 3.1 `pattern_label.py`（核心库）
纯函数，输入 sym/日K，输出标签 dict。无 IO 副作用（行业映射通过参数注入或惰性加载）。

```
classify_shape(kl)     → str   形态标签
classify_volume(rec)   → str   量能标签
classify_sector(sym)   → str   板块联动标签
label(sym)             → dict  {shape, volume, sector, suggest, metrics}
```

### 3.2 `industry_map.py`（行业映射）
- `load_map()` → dict[代码→一级行业]；读 `data/industry_map.json`，缺失返回 {}。
- `refresh()` → 从东财一级行业成分股拉取并落盘（复用 `zijinliu`/`zhuxian` 的 push2delay 拉取逻辑）。
- CLI：`python scripts/industry_map.py --refresh`。

### 3.3 `stock_pattern.py`（单票 CLI）
- `python scripts/stock_pattern.py 000428,001358 [--date 2026-07-29]`
- 输出每只票的三层标签 + 建议归类 + 关键 K 线指标（volatility/breakout/drawdown/vr/seal）。

### 3.4 `fupan_strong_scan.py`（改造）
- 连板梯队前 N 只（默认 8，沿用 `--top`）每只追加一行 pattern 标签。
- 保持现有零散标签向后兼容；pattern 标签作为新增列。

## 4. 三层判定算法

### 4.1 形态 `classify_shape(kl)`（读近 60 日日K）

**核心思路**：判定**本轮上涨启动（首板）的形态**——「横盘后突破」还是「超跌后反抽」。对连板票，回溯到其首板日的前一日为基准看启动形态（避免连板本身抬高指标）。

子指标（**基准日 = 首板前一日**，首板票即昨日；连板票即其 height 那段连板启动前一日）：

| 子指标 | 定义 |
|---|---|
| `volatility20` | 基准日前 20 日 `(high-low)/close` 的均值（横盘度） |
| `peak60` | 基准日前 60 日的最高**收盘**（前期高点） |
| `trough_after_peak` | peak60 之后到基准日的最低**收盘**（回撤低点） |
| `retracement` | `(peak60 - trough_after_peak) / peak60`（前期最大回撤深度） |
| `breakout` | 首板日收盘 / peak60（≥1.0 即突破前期高点） |

> 关键：用 **peak-trough 回撤**（过程指标）而非「今收/60日高」（时点指标）——后者在创新高或反弹中都会失真。

判定规则（互斥，顺序命中；v1 阈值为初值，单元测试固化，**不做胜率回测调参**）：

| 标签 | 条件 | 含义 |
|---|---|---|
| **次新** | 本地数据 < 60 日 | 数据不足，降级 |
| **超跌反抽** | retracement > 15%（前期大跌）且 breakout < 1.0（首板未收复前高） | 借反弹 ❌ |
| **横盘突破** | volatility20 < 4% 且 breakout ≥ 0.99 且 retracement < 10%（前期横盘无大跌） | 资金主动进攻 ✅ |
| **箱体震荡** | volatility20 4%–8% 且 breakout < 0.99（在箱体内未突破） | 中性 |
| **混合** | 以上均不命中 | 交人工研判 |

> **规则顺序**：次新 → 超跌反抽 → 横盘突破 → 箱体震荡 → 混合（先命中先返回）。
> （v1 不设「高位」标签：它与「横盘突破」语义冲突——突破当天必然贴近高点，单凭位置无法区分「刚突破」与「末升段」，末升段由连板高度+量能人工研判。）

**实测验证（2026-07-29）**：
- **华天酒店**（首板 07-27，基准 07-24）：前 20 日横盘 3.0–3.2（volatility20≈3%）+ 07-27 收 3.34 破横盘箱顶（peak60≈3.26，breakout≈1.025）+ 前期无大跌（retracement<10%）→ **横盘突破** ✅，与人工一致。
- **兴欣新材**（首板 07-27，基准 07-24）：peak60≈28.85(07-02) → trough≈20.06(07-21)，retracement≈30%>15% + 07-27 收 22.30 < 28.85（breakout≈0.77<1.0）→ **超跌反抽** ✅，与人工一致。

### 4.2 量能 `classify_volume(rec)`（整合升级现有 strong_scan）

复用 `fupan_strong_scan` 已计算的 `vr`（量比）、`amp`（振幅）、`seal`（封板强度）。

| 标签 | 条件 |
|---|---|
| **一字缩量** | vr < 0.8 且 amp < 1% |
| **缩量** | vr < 0.8 且 amp ≥ 1% |
| **温和放量** | vr 1.0–2.5 且 seal ≥ 0.99 ✅ |
| **爆量烂板** | vr > 3 且 amp 大 且 seal < 0.99 ❌ |
| **放量** | vr > 2.5（其他情况，中性放量） |

> 爆量烂板的「amp 大」v1 取 amp > 5%（主板视角）。创业/科创振幅天然大，按板块限值折算（amp 阈值 ×2）。

### 4.3 板块联动 `classify_sector(sym)`（本地行业映射）

查 `industry_map.json` 得本票一级行业 → 遍历该行业所有成分股当日涨跌（本地 vipdoc）。

| 标签 | 条件 |
|---|---|
| **独狼** | 该行业仅本票涨停，或行业涨幅中位数 < 2% |
| **齐涨(情绪)** | 该行业 ≥ 3 只涨停，或行业涨幅中位数 > 4% |
| **板块漂移** | 行业普涨（中位 2%–4%）但本票涨幅领先行业中位 > 5% |
| **映射缺失** | 本票不在 industry_map 中 |

## 5. 建议归类规则

三层标签 → 建议归类（输出时标注「参考·需人工确认」）。规则优先级从上到下，先命中先返回：

| 形态 | 量能 | 板块 | → 建议归类 |
|---|---|---|---|
| 超跌反抽 | 爆量烂板 | 任意 | **出货烂板**（开板即崩风险） |
| 任意 | 一字缩量 | 任意 | **消息板**（看消息持续性） |
| 任意 | 任意 | 齐涨 | **情绪板**（情绪退则撤） |
| 横盘突破 | 温和放量 | 独狼 | **资金板苗头**（待基本面确认） |
| 其他组合 | — | — | **混合**（人工研判） |

> 「出货烂板」置顶优先：超跌反抽+爆量是最危险组合，无论板块如何都先标红。
> 「资金板苗头」要求最严（三个维度同时好），其余归「混合」交人工——避免过度自信。

## 6. 数据源与降级

| 维度 | 数据源 | 网络 | 降级 |
|---|---|---|---|
| 形态 | 本地 vipdoc `local_kline.read_day` | 零网络 | 数据<60日 → 标「次新」 |
| 量能 | 本地 vipdoc（复用 strong_scan） | 零网络 | 单指标缺失 → 该维度标「数据不足」 |
| 板块联动 | `data/industry_map.json` | 零网络（映射预拉） | 映射缺失 → 标「映射缺失」，不阻断 |

**铁律**：板块联动降级**不阻断**形态/量能输出。三层相互独立，任一缺失只影响该层。

**行业映射刷新**：`python scripts/industry_map.py --refresh`，建议每月一次（新股上市/行业调整）。不自动检测过期（避免每次 fupan 联网）。

## 7. 集成点

### 7.1 fupan 第3步
`fupan_strong_scan.scan()` 返回的连板股（前 N 只）每只增加 `pattern` 字段；`main.py` 渲染时在梯队表追加一列：
```
| 代码 | 高度 | ... | 客观标签 | [横盘突破\|温和放量\|独狼 → 资金板苗头] |
```
- N 沿用 `--top`（默认 8），避免对全部 86 只算板块联动。
- 扫描模块不可用时（import 失败）→ 维持现有降级（纯 checklist），pattern 标签一并缺失，不阻断 fupan。

### 7.2 单票 CLI
```
$ python scripts/stock_pattern.py 000428
华天酒店(000428) · 2026-07-29
  形态: 横盘突破   (volatility 3.1% / breakout 1.04 / drawdown 0.90)
  量能: 温和放量   (vr 2.2 / seal 1.00 / amp 5.8%)
  板块: 独狼       (酒店行业仅本票涨停, 中位+1.3%)
  → 建议归类: 资金板苗头（参考·需人工确认）
```

## 8. 边界条件

| 场景 | 处理 |
|---|---|
| 本地无该票 K 线 | 跳过该票，CLI 标「无本地数据」 |
| 本地数据 < 60 日（次新） | 形态标「次新(数据不足)」，量能/板块照常 |
| 行业映射缺失 | 板块标「映射缺失」，不阻断 |
| 盘中运行 | 标注「盘中未收盘」（沿用 strong_scan 约定） |
| 除权跳空 | volatility/drawdown 可能受扰动；lday 不复权，短期连板影响有限（沿用 strong_scan 假设） |
| fupan_strong_scan import 失败 | fupan 维持现有降级（纯 checklist） |
