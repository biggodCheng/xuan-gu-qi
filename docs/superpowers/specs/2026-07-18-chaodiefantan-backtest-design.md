# 超跌反弹策略回测系统设计

- **日期**：2026-07-18
- **状态**：已认可，待转实现计划
- **回测区间**：2024-01-02 ~ 2026-07-17（约 600 个交易日）
- **关联 skill**：`.claude/skills/chaodiefantan/`
- **关联 memory**：用户实盘画像（负期望过度交易者）、pullback-backtest-finding

---

## 1. 背景与动机

[chaodiefantan](.claude/skills/chaodiefantan/) skill 于 2026-07-18 首次运行（当日创业板 -7.15% 暴跌日，信号 0 只）。skill 是左侧短线策略，但**从未做过历史有效性回测**，无法回答"按纪律执行到底赚不赚钱"、"市值阈值 50-500 亿合理吗"、"是否契合用户实盘"等关键问题。

本设计构建一套事件驱动回测系统，对 2024-01~2026-07 全市场逐日重算超跌反弹信号，模拟纪律退出，产出多维度有效性报告。

### 关键约束（探索阶段实测确认）

| 约束 | 实测结论 | 设计应对 |
|---|---|---|
| chaodiefantan 无历史信号存档 | 不像 [backtest_pullback.py](.claude/skills/qsht-agent/backtest_pullback.py) 可读 `slhc_*.json` 快照 | 必须**逐日重算全市场信号** |
| 新浪 K线不复权 | 实测：茅台 2022-06=1788 真实价、2024-06-19 除权跳空 -1.3% | 弃用新浪 K线做信号判定 |
| 新浪除权接口失效 | `getStockDivistent` → Service not found | 弃用 |
| baostock 不可用 | 3 次重试全部 `10002007 网络接收错误` | 弃用 |
| akshare 东财前复权优秀 | 0.1s/只、除权跳口消除、字段含涨跌幅/换手率 | **采用** |

## 2. 回测目标

1. **策略整体有效性**：按纪律执行（硬止损+被动跟踪出场），2.5 年全市场净收益/胜率/盈亏比/最大回撤，对比创业板指。
2. **信号弹性与最佳持有期**：固定持有 1/3/5/10 日的收益分布、MFE/MAE、平均持有天数，验证"反弹多一日游"。
3. **市值阈值合理性**：分市值带对比表现，回答 50-500 亿是否合理、是否需调整。
4. **与用户实盘的契合度**：信号频率/换手强度对"过度交易"倾向的影响，结合用户画像评估适合度。

---

## 3. 范围与非目标

**范围内**：
- 全 A（当前股票池）逐日重算信号 + 纪律退出模拟 + 4 目标报告
- 双买入口径（T 日收盘 / T+1 开盘）对比
- 附加固定持有 N 日弹性视角

**非目标（YAGNI）**：
- 不还原历史 universe（接受幸存者偏差，标注）
- 不做向量化矩阵优化（逐日循环复用纯函数，2-3 分钟可接受）
- 不接入实时行情/不做每日增量回测（一次性历史回测）
- 不做参数寻优/网格搜索（探索性分析，先看基线表现）

## 4. 数据层设计

### 4.1 数据源选型：方案 B（akshare 东财前复权）

| 数据 | 源 | 用途 |
|---|---|---|
| 股票池 + 当前市值/股本 | 新浪 [get_all_stocks_today](.claude/skills/kangdie/screener/fetcher.py#L47) + [get_market_cap_map](.claude/skills/kangdie/screener/fetcher.py#L203)（运行日一次） | 全 A 池（过滤 ST/N，与实盘一致，约 5314 只）+ 流通股本 = `流通市值 ÷ 收盘价` |
| **前复权日 K** | **akshare `stock_zh_a_hist(symbol, period='daily', start_date, end_date, adjust='qfq')`** | **信号判定**（除权天然消除，跌幅真实） |
| 不复权日 K | akshare `stock_zh_a_hist(..., adjust='')` | 市值估算 = `不复权收盘价 × 当前流通股本` |
| 创业板指 | 新浪 [get_index_kline](.claude/skills/kangdie/screener/fetcher.py#L159)("sz399006") | 基准对比 |

**为什么选 akshare 前复权（而非新浪不复权 + 除权日历过滤）**：
- akshare 前复权实测除权跳口消除（茅台 6-19 由假跌 -1.3% 修正为 +0.75%）、0.1s/只、字段丰富
- 前复权是等比缩放，不改变非除权日的形态/涨跌幅 → 东财前复权信号 = 新浪实盘信号 **去除除权假信号后的版本**，这正是评估"策略本质有效性"所需，且可外推到"修复除权 bug 的实盘"（呼应 darwin 代码债务）
- 单数据源（akshare），工程简洁，总拉取约 16 分钟

### 4.2 拉取与缓存

- **拉取范围**：每只股拉 **2023-09-01 ~ 2026-07-17** 的前复权 + 不复权日 K。起点比回测起点（2024-01-02）早约 80 个交易日，为最早的信号判定留足 70 日前置 buffer；不复权用于市值估算
- **缓存格式**：parquet 面板 `(code, date, open, high, low, close, volume, pct_chg)`，前复权/不复权各一份；约 530 万行/几十 MB
- **增量**：缓存带时间戳，二次运行仅补最新交易日
- **WAF 缓解**（东财限频风险，memory 记录 push2 曾被封、07-18 恢复）：
  1. 正式拉取前**预测试**：连拉 50 只探测是否触发 WAF，大面积失败则中止并提示
  2. 主流程：并发度 ≤ 4、指数退避重试（1s/2s/4s/8s）、断点续拉（按 code 记录已完成）
  3. 每 100 只 sleep 0.5s

### 4.3 市值估算

```
当前流通股本(股) = get_market_cap_map()[code] × 1e8 ÷ get_all_stocks_today().close
历史流通市值(t) = 当前流通股本 × 不复权收盘价(t) ÷ 1e8   # 亿元
```

- 股本视为 2.5 年常数（忽略解禁/增发/回购导致的变动）
- 偏差方向：2024 年初实际小盘股可能被误算为 ≥50 亿而漏选；标注

## 5. 信号层设计

### 5.1 逐日扫描

对回测区间每个交易日 T（2024-01-02 ~ 2026-07-17），遍历股票池每只股：
1. 取该股前复权 K 线中 T 及之前的数据，切到"以 T 日为最后一根"的窗口（≥70 日）
2. 估算 T 日流通市值（4.3）
3. 调用现有纯函数 [is_oversold_rebound](.claude/skills/chaodiefantan/screener/analyzer.py#L28)(bars, market_cap_at_T) —— **复用，不重写**，保证回测信号与实盘判定逻辑完全一致
4. 通过则记录信号

### 5.2 信号字段

```json
{
  "signal_date": "2024-03-15",
  "code": "600xxx",
  "name": "...",
  "close_T": 12.34,
  "stop_loss": 11.50,        // T-1 日最低，硬止损位
  "drop5": -18.2,
  "vol_ratio": 2.1,
  "market_cap_T": 120.0,
  "buy_price": 12.34         // T 日收盘（主口径）
}
```

### 5.3 信号去重

同一只股若上一信号在 **5 个交易日**内，视为同一波反弹，**不重复计入**（避免连续阳包阴重复计数）。去重窗口常量化，可在 `simulator.py` 顶部调整。

### 5.4 预期信号量

超跌反弹是稀有信号（2026-07-18 暴跌日 0 只）。预计全区间信号数**几十到几百量级**，属小样本探索性分析，报告显著标注"非统计显著"。

## 6. 回测引擎设计

### 6.1 买入假设（双口径）

| 口径 | 买入价 | 用途 |
|---|---|---|
| 主口径 | T 日收盘价 | 符合 skill"尾盘执行"实盘习惯，不被次日高开惩罚 |
| 对照口径 | T+1 开盘价 | 稳健性对照（避免未来函数嫌疑），反映次日追高成本 |

两口径独立跑，报告对比差异（差异大说明信号次日普遍高开吞噬收益）。

### 6.2 退出逻辑（纪律执行 · 主口径 = 盘中触及即止损）

```
买入后从 T+1 日开始逐日检查（T 日当天不动，A股 T+1）:
  每日按顺序判定:
    ① 硬止损(防守): 当日 low ≤ stop_loss(信号日 T-1 最低,固定值)
                    → 以 stop_loss 价出局 [盘中触及即砍,不看收盘]
    ② 被动跟踪出场(进攻): 当日 close < 前一交易日 low
                    (基准每日动态更新:T+1 比 T 日 low,T+2 比 T+1 low…反弹中 low 抬高则基准上移)
                    → 以当日 close 价出局 [让利润奔跑,动能转弱落袋]
       (①②同日触发: ①优先)
    ③ 自 T+1 起持满 10 个交易日(即 T+10 日)仍未触发①② → T+10 日收盘强平 [短线兜底]
```

**逻辑说明**：
- ① 是固定底线防守，防单日暴跌砸穿信号底
- ② 是移动跟踪：反弹中每日最低价抬高，跟踪基准上移；收盘跌破抬高的基准 = 动能转弱。盈利时起跟踪止盈（锁盈），亏损时起移动止损
- ① 盘中触发优先于 ② 收盘判定（更紧急）

### 6.3 成本模型

复用 [backtest_strategy.py](scripts/backtest_strategy.py#L127) 口径：
- **净费** `FEE = 0.0008`：印花税 0.05%（卖出单边）+ 双边佣金万 2.5 + 过户
- **含滑点** `FEE_SLIP = 0.002`：净费 + 约 0.12% 滑点（保守）
- 每笔按 `(买额 + 卖额) × FEE` 扣除，报告两档并列

### 6.4 基准

创业板指（sz399006）同区间涨幅。超跌反弹在下跌市触发，创业板指是高波动可比基准。报告对比策略是否跑赢。

### 6.5 附加视角（目标 2，零额外成本）

同一批信号另算"固定持有 1/3/5/10 日、不止盈不止损"的原始收益 + MFE/MAE，验证反弹弹性与最佳持有期。

## 10. 验证策略

- **单测**：`simulator.py` 三种出场（硬止损/被动跟踪/强平）用构造 K 线验证；去重逻辑单测
- **对账**：抽 3-5 个信号手工核对买入价/止损价/出场价/收益
- **数据 sanity**：
  - 茅台除权日（如 2024-06-19）前复权连续性（无跳空）
  - 信号总数合理性（稀有信号，预期几十~几百）
  - 双口径差异幅度（T 日收盘 vs T+1 开盘）

## 11. 关键决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 数据源 | akshare 东财前复权 | 实测质量最优、除权天然消除、单源简洁 |
| 信号判定 | 复用 `is_oversold_rebound` | 回测信号 = 实盘信号（同逻辑），结论可外推 |
| 引擎架构 | 逐日事件循环（非向量化） | 复用纯函数，2-3 分钟可接受，避免重写信号逻辑 |
| 退出模型 | 硬止损 + 被动跟踪出场 | 用户拍板：底线防守 + 让利润奔跑 |
| 止盈 | 被动跟踪（非固定 +6%） | 移动跟踪锁盈优于固定目标，让强势反弹充分奔跑 |
| 市值估算 | 不复权价 × 当前股本 | 简洁，偏差可接受并标注；如需更严谨后续加送转回推 |
| Universe | 当前全 A（不还原历史） | 还原成本过高，标注幸存者偏差方向即可 |
