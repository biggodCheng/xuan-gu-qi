## 一、选股篇：高手选股核心逻辑

### 1. 散户误区 vs 高手核心

很多散户选股总埋头深挖公司利好、研究各类消息，陷入"单纯找好股票"的误区；而市场里能稳定盈利的交易者，核心思路从来都是**寻找有资金运作的标的**，紧盯**趋势、资金、股价位置**三大关键。

| 视角 | 着眼点 |
|------|--------|
| **散户误区** | 只看利好，不看资金 |
| **高手核心** | 抓主线趋势 + 选有资金记忆强势股 + 判断股价位置 + 观察下跌承接力度 |

高手靠一套标准化流程筛选标的，**管住情绪、严格执行**才是盈利关键。

> 投资有风险，操作需谨慎。

### 2. 高手完整选股顺序（自上而下 5 步总览）

1. **看市场** → 看大盘环境，锁定当日主线题材是谁
2. **看板块** → 找出持续走强、资金扎堆的板块
3. **选个股** → 锁定板块内活跃度最高、走势最强的标的
4. **看位置** → 避开高位追涨，寻找低风险舒适介入区间
5. **看承接** → 确认有主力资金持续运作再出手

> 仅供静态分析，不构成投资建议及买卖依据，据此操作风险自担。

下面按这 5 步逐项展开实战标准。

### 3. 第 2 步详解：板块选股实战标准

判断一个板块是否值得介入，看**三大条件**：

1. **板块有连续上涨**（不是单日突发大涨）
2. **有明确龙头个股领涨**（不是零散个股无规律拉升）
3. **板块反复活跃**（代表场内资金持续驻扎，没有离场）

> 核心总结：没有板块行情加持的独立个股，上涨行情大概率很难持续走远。

#### 📊 实战量化标准（可勾选）

三大条件必须**同时满足**才算"有板块行情"，缺一即只算零散个股：

| 条件 | 量化判定 | 勾选口径 |
|------|----------|----------|
| **① 连续上涨** | 板块指数近 5 日**≥3 日收阳**且 5 日累计涨幅为正（排除单日突发大涨） | 看 `zhuxian` 板块近 5 日 K 线 |
| **② 龙头领涨** | 板块内**至少 1 只涨停**，且该股位于板块涨幅前 3（不是尾部跟风股零散拉升） | 涨停阈值：主板≥9.5% / 科创创业≥19.5% / 北交所≥29.5% |
| **③ 反复活跃** | 板块**近 20 日登上主线榜（`zhuxian`）≥2 次**，说明资金持续驻扎而非一日游 | 查近 20 日 `zhuxian` 历史 |

> 三条全中 = 板块行情确立，方可进入第 3 步选个股；缺任一条 → 回到第 1 步重看市场。

### 4. 第 3 步详解：核心思路——做"有资金记忆"的票

**核心逻辑**：成熟交易者很少埋伏长期冷门、无人关注的个股。资金有记忆效应——曾经被资金炒作过一次的标的，后续更容易再度吸引资金回流拉升。

**优先选择三类个股**：

1. 板块龙头股
2. 前期走出过强势行情的个股
3. 中长期反复异动活跃的个股

**实战筛选 3 个信号**：

1. 近期涨停、大阳线数量多，历史走势强势
2. 股价回调调整之后，能够快速被资金重新拉起
3. 只要股价出现异动拉升，同步伴随成交量明显放大

> 这类票的本质是：**市场已经认可它，而不是你觉得它好。**

#### 📊 实战量化标准（可勾选）

三类优先标的 + 三信号筛选，对应 `zhangting` / `qsht-agent` 体系：

| 维度 | 量化判定 | 数据来源 |
|------|----------|----------|
| **三类优先** | ① 板块龙头（板块涨幅第 1 且涨停）<br>② 前期强势股（近 60 日内有 ≥2 次涨停）<br>③ 反复异动股（近 60 日登上 `renqibang` 人气榜 ≥2 次） | `zhangting` / `renqibang` |
| **信号① 涨停多** | 近 15 日涨停 ≥1 次，或近 20 日大阳线（>5%）≥3 根 | `zhangting` |
| **信号② 回调快拉** | 涨停后回调不破涨停实体 50%，且缩量企稳后被资金重新拉起（回调段量比 <0.8，拉起日放量 >1.2） | 日 K + 量 |
| **信号③ 异动放量** | 任何异动拉升日，成交量 > 前 5 日均量 ×1.5（明显放大） | 日 K 量 |

> 三信号命中 ≥2 个即视为"有资金记忆"，进入第 4 步看位置。

### 5. 第 4 步详解：看位置，决定能不能上车

同一只股票，位置不同，结果完全不同。高手特别在意"性价比"，划分三种典型位置：

| 位置 | 特征 | 含义 |
|------|------|------|
| **启动位** | 刚突破、刚放量；市场开始关注 | 风险小，空间大 |
| **洗盘位** | 涨过一波后震荡；走势看起来"不行了" | 很多人被洗出去 |
| **高位加速** | 连续大涨；市场情绪高度一致 | 容易接最后一棒 |

**高手判断位置的核心目的**：分清当前这笔交易属于**左侧布局**，还是**右侧顺势交易**。

#### 📊 实战量化标准（可勾选）

用"距 20 日低点涨幅 + 均线 + 量能"三要素定位，避开追涨：

| 位置 | 量化判定 | 操作建议 |
|------|----------|----------|
| **✅ 启动位** | 距 20 日低点涨幅 **<15%** + **刚突破 MA20**（收盘站上 MA20 不超 3 日）+ 突破日**放量**（>5 日均量×1.2） | 低风险介入区，左侧布局首选 |
| **✅ 洗盘位（回踩买点）** | 涨过一波后**回踩 MA10/MA20 缩量企稳**（回踩段量比 <0.8，企稳日不破均线） | 右侧顺势回踩买点（详见第 5 步承接） |
| **❌ 高位加速** | 距 20 日低点涨幅 **>40%** + **连续大阳**（近 5 日≥3 根>5%）+ **加速放量**（量能持续递增） | 接最后一棒风险区，**不追** |

> 介于启动位与高位加速之间（涨幅 15%–40%）= 正常趋势中继，结合承接信号找买点。

### 6. 第 5 步详解：看"承接"，决定买不买

很多人选股眼光尚可，但买点把握很差。高手重点观察的细节指标是**承接**。

**通俗解释**：

- 股价下跌时，有没有资金主动买入承接
- 盘中大单砸盘时，股价能不能稳住不深跌

**承接有力的 3 个实战信号**：

1. 下跌阶段成交量明显缩量，说明持股资金不愿割肉抛售
2. 回调时不会跌破关键支撑价位
3. 分时图出现砸盘后，有资金快速拉升收回失地

> 核心要点：判断个股强弱**不要只看上涨力度，重点看下跌时有没有资金承接护盘**。

#### 📊 实战量化标准（可勾选）

承接是**买点维度**（非成色筛选），用日 K 三信号量化（已在 `eval-stock` 第 7 维实现）：

| 信号 | 量化判定 | 含义 |
|------|----------|------|
| **① 下跌缩量** | 下跌段量比 **<0.8**（近 5 日均量 / 近 20 日均量） | 持股资金惜售，不愿割肉 |
| **② 不破支撑** | 回调近 10 日最低点 **≥ 回调前 20 日最低点 ×0.98**（即回撤不破前低 2%） | 关键支撑守住 |
| **③ 砸盘收回** | 长下影线占当日振幅 **≥50%**（下影/(最高-最低)） | 砸盘后有资金快速收回 |

| 命中数 | 判定 | 操作 |
|--------|------|------|
| **≥2** | ✅ 承接有力 | 可择机出手 |
| **=1** | ➖ 承接一般 | 趋势在但等买点，不急于进场 |
| **=0** | ❌ 承接弱 | 不参与，等承接信号出现 |

## 二、复盘篇：高手的复盘顺序

> **核心底层逻辑**：理清资金是怎么进场，又打算流向哪里。
>
> **⚙️ 已落地为 `fupan` skill**：本篇 5 步（看大盘 → 看主线 → 拆强势股 → 看失败案例 → 写次日剧本）已落地为每日复盘 skill，串联 `market_regime`（市况总开关）/ `zhuxian`（主线）/ `renqibang`（人气）等现有工具，产出「次日剧本.md」（三套应对预案）。每日收盘后 5–10 分钟跑一次。与 `trade_review.py`（周复盘·盯账户纪律）互补：一个向外看市场，一个向内看自己。

无效复盘不如不复盘！高手复盘的整体框架是：**判大盘环境 → 抓资金主线 → 拆解强势股 → 复盘亏损交易 → 提前做次日多套行情预案**。用工具简化筛选，拒绝情绪化随意交易，短线少走弯路。

### 1. 第 1 步：先看大盘——不看涨跌看状态

很多人复盘第一步思路就出错。**不纠结单日指数收涨还是收跌**，只重点观察三点：

- **结构**：指数当前是上升趋势、区间震荡，还是反弹行情末尾
- **量能**：放量代表资金进攻，缩量代表市场观望情绪浓厚
- **权重 vs 题材**：权重板块在护盘托指数，还是题材小票在主导行情

> 目的：判断次日行情适不适合操作，应当主动出击还是轻仓少动。

#### 📊 实战量化标准（可勾选）

三维度量化判定（数据：上证/创业板指日 K + 全市场成交额）。**先跑 `market_regime` 拿市况总开关 🔴/🟡/🟢，再按下表逐维研判**：

| 维度 | 状态 | 量化判定 |
|------|------|----------|
| **结构（趋势位置）** | 上升 | 收盘 >MA20 **且** MA5>MA10>MA20（多头排列） |
| | 震荡 | MA5/10/20 缠绕交织、收盘在 ±5% 区间内反复 |
| | 反弹末尾 ⚠️ | 反弹中**价升量缩**（背离），或触及前高密集成交区 |
| | 下跌 | 收盘 <MA20 **且** MA5<MA10<MA20（空头排列） |
| **量能** | 放量（进攻） | 当日成交额 > 5 日均量 ×**1.2** |
| | 平量（观望） | 0.8–1.2 倍之间 |
| | 缩量（观望浓） | 当日成交额 < 5 日均量 ×**0.8** |
| **权重 vs 题材** | 权重护盘（虚涨） | 上证强 + 创业板弱 → 指数好看但赚钱效应差 |
| | 题材主导 | 创业板/中证1000 强 + 上证弱 → 赚钱效应在中小票 |
| | 同涨同跌 | 正常，无分化 |

> **市况总开关**（直接复用 `market_regime`）：🔴退守市→剧本直接落"空仓观望"；🟡防守市→半仓做个股；🟢进攻市→正常仓位。这是第 0 步，决定"要不要操作"。

### 2. 第 2 步：看主线和支线——资金在哪抱团

深度复盘，核心一定围绕市场主线题材展开。每日至少梳理清楚**三件事**：

1. 今日市场最强题材方向
2. 是否出现新的题材分支正在发酵
3. 原有老主线处于**加速上涨、分歧震荡、还是退潮下跌**阶段

> 核心总结：短线行情的盈利机会，只会集中在市场最强的一小批个股之间轮动。

#### 📊 实战量化标准（可勾选）

调 `zhuxian`（主线 Top10）+ `renqibang`（人气方向）梳理三件事，**核心是老主线阶段判定**：

| 三件事 | 判定口径 |
|--------|----------|
| **① 最强题材** | `zhuxian` Top1 板块 + `renqibang` 上榜原因（资金关注什么） |
| **② 新分支发酵** | 首次进入 `zhuxian` 榜 / 首次登上 `renqibang` 的概念（昨日不在、今日新进） |
| **③ 老主线阶段** | 见下表 |

**老主线阶段判定（四阶段，决定参与姿势）：**

| 阶段 | 信号标准 | 应对 |
|------|----------|------|
| **🟢 启动期** | 板块**首日放量大涨（>3%）**、涨停家数从 <3 增至 **≥5** | 左侧关注/布局 |
| **🟢 加速期** | 龙头连板、板块**连续 ≥3 日大阳**、涨停家数**逐日递增** | 右侧顺势（注意位置，避开高位加速股） |
| **🟡 分歧期** | **放量长上影**（上影 > 实体 2 倍）、**烂板增多**（炸板回封）、龙头滞涨但放量 | 警惕，准备止盈，不追加 |
| **🔴 退潮期** | **龙头断板**、板块跌幅 >2%、涨停家数**较峰值骤减 ≥50%** | 离场，不参与 |

> 主线阶段是仓位与去留的总指挥：加速期可顺势，分歧期收手，退潮期离场。

### 3. 第 3 步：看强势股上涨过程

高手复盘强势股，重点拆解完整上涨过程：

- **首板涨停属性**：属于情绪推动、纯资金炒作，还是利好消息刺激
- **连板阶段**：有无健康换手、下跌时资金承接力度如何
- **分歧节点**：分歧后被资金砸崩走弱，还是有资金承接再度走强

> 逻辑：这些细节直接决定个股次日是适合**接力买入**，还是主力**借机出货**的风险点。

#### 📊 实战量化标准（可勾选）

从主线板块挑**涨幅前 3 + 连板高度前 3**，按三维度拆解：

| 维度 | 分类 | 量化判定 | 次日含义 |
|------|------|----------|----------|
| **首板属性** | 情绪板 | 板块多股齐涨停、消息面无实质利好、换手 **>20%** | 看情绪，情绪退则撤 |
| | 资金板 | 独立于板块、放量突破平台、龙虎榜机构/游资介入 | 相对可持续，可跟踪 |
| | 消息板 | 对应明确利好（政策/业绩/事件）、一字或秒板 | 看消息持续性，易一日游 |
| **连板健康度** | 健康 ✅ | 连板中换手 **10%–25%**、量能温和放大（非爆量也非缩量一字） | 接力充分，可跟踪 |
| | 不健康 ❌ | 连续一字（无换手）/ 爆量烂板（分歧过大） | 开板即崩风险 |
| **分歧节点** | 被砸崩 ❌ | 分歧日放量长阴 / 跌停 | **不接力** |
| | 承接走强 ✅ | 分歧日缩量企稳后再度涨停（承接信号参考第 5 步选股·承接） | **可接力** |

> 三维度综合判定次日属性：首板看可持续性、连板看健康度、分歧节点决定接力还是出货。

### 4. 第 4 步：看失败案例

成熟交易者复盘一定会研究亏损、走坏的标的——不是单纯自我否定，而是复盘总结出错原因：

- **典型问题**：盲目追高、踏错行情节奏
- **模式外冲动**：属于自己固定交易模式之外的冲动交易
- **环境恶劣**：市场整体环境本就不适合进场操作

> 复盘核心标准：能清晰判断这笔亏损是否属于**可规避的不合理亏损**，交易认知就会明显提升。

> 亏钱不可怕，可怕的是稀里糊涂亏损。不少股民亏了钱只会懊恼、抱怨市场，从不静下心复盘亏损根源！只有理清每一笔亏损背后的逻辑，才能规避重复踩坑，让每一次亏损都变成积累经验的学费，交易水平才能稳步上台阶。

#### 📊 实战量化标准（可勾选）

本步看**市场层面**的走坏标的（炸板/断板/高位放量长上影），归类亏损根源。**自己账户的失败交易由 `trade_review.py` 周复盘覆盖，这里不重复。**

扫描当日三类走坏标的：

| 走坏类型 | 量化判定 | 含义 |
|----------|----------|------|
| **炸板股** | 盘中触及涨停但未封住（开板） | 当日追板资金被套 |
| **断板股** | 昨日连板、今日未能继续（连板终结） | 接力资金被套 |
| **高位放量长上影** | 高位区上影 > 实体 且 放量（>5 日均量×1.2） | 主力借机出货信号 |

归类亏损根源（对齐"可规避的不合理亏损"）：

| 类型 | 量化判定 | 教训 |
|------|----------|------|
| **追高** | 买入点距 5 日高点 >**15%**，或已在 ≥3 板后追入 | 不追加速段 |
| **模式外冲动** | 非主线板块、qsht 漏斗外的标的 | 只做模式内 |
| **环境恶劣** | `market_regime` = 🔴退守市时强行操作 | 退守市不动手（80% 大亏发生于此） |

> 能把每笔潜在亏损归入上表某一类，就完成了"从懊恼到认知"的转化。

### 5. 最后一步：写好「明天的剧本」

高手复盘会提前做好多情景交易预案，并非单纯预判涨跌，而是**分情况制定应对方案**：

- **主线题材继续走强**：提前锁定重点关注的个股方向
- **板块出现分歧震荡**：提前规划止损位置、离场标准
- **市场情绪全面走弱**：直接空仓观望，减少操作

> 核心区分：不是赌单边涨跌的预测，而是覆盖不同行情的**应对预案**。

#### 📊 实战量化标准（可勾选）

三套情景，每套必须有**明确的触发信号 + 对应操作 + 仓位**。**不到确认信号不动手**（对齐"少交易+严纪律"）：

| 情景 | 触发信号（确认信号） | 操作 | 仓位 |
|------|----------------------|------|------|
| **A 主线继续走强** | 龙头高开秒板 / 继续连板，板块涨停家数不减 | 锁定主线内强势股，按 `qsht-agent` 选接力标的 | 🟢进攻市正常 / 🟡防守市半仓 |
| **B 分歧震荡** | 龙头高开低走 / 烂板增多，板块涨跌互现 | 持股者设止损（破 MA10 或前日低点），**不追加** | 🟡半仓以下 |
| **C 全面走弱** | 龙头断板 / 低开，创业板跌 >1%，涨停家数骤减 | **空仓观望**，止损离场 | 🔴空仓 |

> **剧本铁律**：写剧本不是预测明天涨跌，而是"如果 A 我就做 X，如果 B 我就做 Y，如果 C 我就空仓"。信号触发前，手放在口袋里。

### 6. 复盘效率 > 复盘时长

借助量化工具筛选市场强度、资金流向、情绪拐点，结合人工深度研判，能大幅减少无效操作，避开短线交易弯路。

> 本稿复盘 5 步已全部落地为 `fupan` skill 的量化标准 + checklist，跑一次约 5–10 分钟产出「次日剧本.md」，拒绝情绪化随意交易。
